stuck

動詞・形容詞/stʌk/CEFR B1英検3級 #564
  1. 【形容詞】（身体や物が）はまり込んだ、動かなくなった、身動きが取れない（unable to move or escape from a position）
  2. 【形容詞】（問題・課題などで）行き詰まった、解けない、先に進めない
  3. 【形容詞】（～に粘着して）付着した、くっついた
  4. 【動詞】stick の過去形・過去分詞。～にはまり込ませる、～を引っ付ける

⛏️ マインクラフト例文

⛏I got stuck in the sand block again!

また砂ブロックにはまり込んでしまった！

/aɪ ɡɑt̚ stʌk ɪn ðə sænd̚ blɑk əˈɡɛn/
  • got の語末 /t/ が stuck の /s/ に子音+子音で続き、got の /t/ は未開放 [ɡɑt̚ stʌk]
  • stuck の語末 /k/ が in の /ɪ/ に連結 [stʌk ɪn]
  • sand の語末 /d/ が block の /b/ に子音+子音で、sand の /d/ は未開放 [sænd̚ blɑk]

  • is の語末 /z/ が stuck の /s/ に子音+子音で続く（連結なし）
  • the は /ðə/ で block の /b/ 前 [ðə blɑk]
  • won't の語末 /t/ が move の /m/ に未開放で続く [woʊnt̚ muːv]
