imperfect

形容詞・名詞/ɪmˈpɝfɪkt/CEFR B1英検準1級 #671
  1. 【形容詞】欠陥のある、不完全な（品質や実行に問題・不足がある。例: an imperfect tool）
  2. 【形容詞】不十分な、曖昧な（情報や知識が完全でない。例: imperfect information）
  3. 【名詞】（文法）過去未完了形（過去に継続・習慣・反復を表す時制）

⛏️ マインクラフト例文

⛏This design is imperfect, but I can still use it to build my house.

この設計は不完全だが、それでも家を建てるのに使える。

/ðɪs dɪˈzaɪn ɪz ɪmˈpɝfɪkt bət aɪ kən ˈstɪl ˈjuːz ɪt tu bɪld maɪ haʊs/
  • design is → design の語末 /n/ が is の /ɪ/ に連結 [zaɪn ɪz] →「ザイニズ」
  • use it → it の語末 /t/ は未開放で [juːz ɪt̚ tu] →「ユーズ・イッ・トゥ」
ザィス・デザイニズ・インパーフェクト・バッ・アイ・カン・スティル・ユーズ・イッ・トゥ・ビルド・マイ・ハウス

⛏My pickaxe is imperfect; it breaks if I mine too much stone.

私のツルハシは不完全だ。石をあまり採掘すると壊れる。

/maɪ ˈpɪkæks ɪz ɪmˈpɝfɪkt ɪt ˈbreɪks əf aɪ ˈmaɪn tu mʌtʃ stoʊn/
  • pickaxe is → pickaxe の語末 /s/ が is の /ɪ/ に連結 [ˈpɪkæks ɪz] →「ピカックスイズ」
  • breaks if → breaks の /z/ と if の弱形 /əf/ が連結 [ˈbreɪks əf] →「ブレイクスァフ」
マイ・ピカックスイズ・インパーフェクト・イッ・ブレイクスァフ・アイ・マイン・トゥ・マッチ・ストウン

⛏You need an imperfect map to explore and find rare biomes naturally.

珍しいバイオームを自然に探索して見つけるために、不完全なマップが必要だ。

/ju niːd ən ɪmˈpɝfɪkt mæp tu ɪkˈsploɚ ənd faɪnd reɪr baɪˈoʊmz ˈnætʃərəli/
  • need an → need の /d/ が an の /ə/ に連結 [niːd ən] →「ニードアン」、an の /n/ が imperfect の /ɪ/ に連結 [ənimp]
  • to explore → to の弱形 /tə/ が explore の /ɪk/ に連結 [tə ɪk] →「タ・イク」
