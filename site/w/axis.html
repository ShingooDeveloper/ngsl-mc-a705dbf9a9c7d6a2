axis

名詞/ˈæk.sɪs/CEFR B2英検準1級 #3064
  1. 【名詞】回転の中心となる線や軸（the line around which something rotates: 回転物が回る中心の線）
  2. 【名詞】座標系における測定基準線（reference line in a coordinate system: X軸・Y軸・Z軸などの基準線）
  3. 【名詞】建築物の対称性の中心軸（line of symmetry: 構造物の左右対称や前後の中心軸）

⛏️ マインクラフト例文

⛏The axis of rotation must align with the center of the build.

回転軸は建築物の中心と一致する必要があります。

/ðə ˈæk.sɪs əv ɹoʊˈteɪʃən̚ mʌs̚t əˈlaɪn wɪð ðə ˈsɛn.tɚ əv ðə bɪld/
  • axis の /s/ が母音 /ə/ に連結。of は弱形 /əv/ [ˈæk.sɪs əv]→「アクシス アヴ」
  • rotation の /n/ が未開放である [ɹoʊˈteɪʃən̚ mʌs̚t]→「ロウテイション マスト」
  • must の /t/ が未開放で align に先立つ [mʌs̚t əˈlaɪn]→「マスッ アライン」
ザ アクシス アヴ ロウテイション マスッ アライン ウィズ ザ センター アヴ ザ ビルド

⛏Move the spawner along the Y-axis to change its height.

スポーナーをY軸に沿って移動させて高さを変える。

/muv ðə ˈspo.nɚ əˈlɔŋ ðə ˈwaɪ ˈæk.sɪs tə tʃeɪndʒ ɪts haɪt/
  • spawner の /ɚ/ が母音 /ə/ に連結 [ˈspo.nɚ əˈlɔŋ]→「スポーナー ア ロング」
  • axis の /s/ が次の子音に続く。to は弱形 /tə/ [ˈæk.sɪs tə]→「アクシス タ」
  • change の /dʒ/ が母音 /ɪ/ に連結 [tʃeɪndʒ ɪts]→「チェンジ イッツ」
ムーヴ ザ スポーナー ア ロング ザ ワイ アクシス タ チェンジ イッツ ハイト

⛏The piston axis should be horizontal if you're building a sliding door.

スライド式ドアを作っているなら、ピストンの軸は水平である必要があります。

/ðə ˈpɪs.tən̚ ˈæk.sɪs̚ ʃʊd̚ bi hɔɹ.əˈzɑn.təl ɪf juɹ ˈbɪl.dɪŋ ə ˈslaɪ.dɪŋ ˈdɔɹ/
  • piston の /n/ が未開放である [ˈpɪs.tən̚ ˈæk.sɪs]→「ピストン アクシス」
  • axis の /s/ が未開放で should に先立つ [ˈæk.sɪs̚ ʃʊd]→「アクシス シュッド」
  • should の /d/ が未開放である。be は弱形 /bi/ [ʃʊd̚ bi]→「シュッ ビー」
