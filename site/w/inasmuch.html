inasmuch

接続詞/ɪnəzˈmʌtʃ/CEFR C1ターゲット1000 #775
  1. 【接続詞】～である限り、～という点で（...の範囲で～である）
  2. 【接続詞】～であるので、～という理由で
  3. 【接続詞】～として、～の立場で（...の役割や見方で～である）

⛏️ マインクラフト例文

⛏This ore is valuable inasmuch as it can be smelted into ingots.

このオーはインゴットに製錬できるという点で価値がある。

/ðɪs ɔr ɪz ˈvæljuəbəl ɪnəzˈmʌtʃ əz ɪt kən bɪ ˈsmɛltɪd ɪntə ˈɪŋɡɑts/
  • "valuable" の語末 /l/ が "inasmuch" の /ɪ/ に連結
  • "inasmuch" の語末 /tʃ/ が "as" の弱形 /ə/ に連結、"as" は弱形 /əz/、語末 /z/ が "it" の /ɪ/ に連結
  • "smelted" の語末 /d/ が弱形 "into" /ɪntə/ の /ɪ/ に連結
ディス オー イズ ヴァリュアブルイナズマッチアズイット キャン ビー スメルティドイント イングッツ

⛏We should protect this forest inasmuch as it provides wood for crafting.

このフォレストは木材を提供するという点で保護すべき。

/wi ˈʃʊd prəˈtɛkt ðɪs ˈfɔrɪst ɪnəzˈmʌtʃ əz ɪt prəˈvaɪdz wʊd fɔr ˈkræftɪŋ/
  • "forest" の語末 /t/ が "inasmuch" の /ɪ/ に連結
  • "inasmuch" の語末 /tʃ/ が "as" の弱形 /ə/ に連結、"as" は弱形 /əz/、語末 /z/ が "it" の /ɪ/ に連結
ウィ シュッド プロテクト ディス フォリストイナズマッチアズイット プロヴァイズ ウッド フォー クラフティング

⛏Diamonds are rare inasmuch as they spawn only at low Y-levels.

ダイヤモンドは低いY値にしかスポーンしないという点で希少である。

/ˈdaɪəmɑndz ɑr ˈrɛr ɪnəzˈmʌtʃ əz ðeɪ spɔn ˈoʊnli æt loʊ ˈwaɪ ˈlɛvəlz/
  • "rare" の語末 /r/ が "inasmuch" の /ɪ/ に連結
  • "inasmuch" の語末 /tʃ/ が "as" の弱形 /ə/ に連結。"as" と "they" は子音 /z/ と /ð/ の隣接のため連結なし

💬 よく使う熟語（マイクラ例文）

inasmuch/in as much as …～する限りでは、～だから（理由や条件を示す）ターゲット1000 #775

⛏Inasmuch as diamond ore is rare, we must search deep underground to find it.

ダイヤモンド鉱石は希少だからこそ、深い地下を探索してそれを見つけ出す必要がある。

[ɪnəzˈmʌtʃ əz ˈdaɪmənd ɔɹ ɪz ɹɛɹ wi mʌst sɝtʃ diːp ˌʌndɚˈɡɹaʊnd tə ˈfaɪndɪt]
  • as → 弱形 /əz/、短く「アズ」と聞こえる
  • to → 機能語は弱形 /tə/ に弱化、「タ」程度の音
  • find it → find の語末子音 /d/ が it の初母音 /ɪ/ に連結 [ˈfaɪndɪt] ファインディット
インアズマッチ、アズ、ダイマンド、オア、イズ、レア、ウィー、マスト、サーチ、ディープ、アンダーグラウンド、タ、ファインディット
