dusk

名詞/dʌsk/CEFR B1英検準1級 #1613
  1. 【名詞】薄暮、夕暮れ（日没直後の薄い暗さの時間帯）
  2. 【名詞】夕焼け直後から夜間にかけての過渡期、たそがれ時
  3. 【名詞】（時間を示す文脈で）夕方、傍晩（ぼうばん）

⛏️ マインクラフト例文

⛏We need to find shelter before dusk falls.

夕暮れが訪れる前にシェルターを見つける必要があります。

/wiː ˈniːd tə ˈfaɪnd ˈʃɛltər bɪˈfɔr ˈdʌsk fɔlz/
  • need to → need の語末 /d/ が to の弱形 /ə/ に連結 [ˈniːdə] ニーダ
ウィー ニーダ ファインド シェルター ビフォー ダスク ファルズ

⛏At dusk, hostile mobs spawn everywhere.

夕暮れ時には敵モブがいたるところで出現します。

/æt ˈdʌsk ˈhoʊs.tl̩ ˈmɑbz ˈspɔːn ˈɛvrɪ.wɛr/
  • at dusk → at の語末 /t/ が未開放、dusk との間に連結なし [æt̚ ˈdʌsk] アッ ダスク
  • spawn everywhere → spawn の語末 /n/ が everywhere の母音に連結 [ˈspɔːn ˈɛvrɪˌwɛr] スポーン エブリウェア
アッ ダスク ホウステル マブズ スポーン エブリウェア

⛏During dusk, I always return to my base.

夕暮れの間、私はいつも自分の拠点に戻ります。

/ˈdʊrɪŋ ˈdʌsk aɪ ˈɔlweɪz rɪˈtɜrn tə maɪ ˈbeɪs/
  • return to → return の語末 /n/ が to の弱形 /ə/ に連結 [rɪˈtɜrnə] リターナ
  • to my → to の弱形 /tə/ の /ə/ が my の母音に連結 [tə maɪ] タ マイ
デュアリング ダスク アイ オルウェイズ リターナ タ マイ ベイス
