close

動詞・形容詞/kloʊz/CEFR A2頻度#238
  1. 【動詞】shut（…を閉じる；ドアやチェストなど）
  2. 【形容詞】near（近い；…に接近している）
  3. 【形容詞】intimate/tight（親密な；密接した）
  4. 【動詞】end/finish（終わる；終える）

⛏️ マインクラフト例文

⛏Close the chest before the mobs find it.

モブに見つかる前にチェストを閉じてください。

/ˈkloʊz ðə ˈtʃɛst bɪˈfɔr ðə ˈmɑbz ˈfaɪnd ɪt/
  • close の z が the の ə に連結 [ˈkloʊzə]
  • before の r が the の ə に連結 [bɪˈfɔrə]
  • find の d が it の ɪ に連結 [ˈfaɪndɪt]
クローザ チェスト ビフォーラ モブズ ファインディット

⛏The creeper is dangerously close to me!

クリーパーが危なく近い距離にいます！

/ðə ˈkripər ɪz ˈdeɪndʒərəsli ˈkloʊs tə mi/
  • creeper の r が is の ɪ に連結 [ˈkripərɪz]
  • to は弱形 /tə/
ザ クリーパーイズ デインジャーラスリ クロース タ ミー

⛏You need to close the gate when you're close to the base.

基地に近い時にゲートを閉じる必要があります。

/ju ˈnid tə ˈkloʊz ðə ˈɡeɪt wɛn jɔr ˈkloʊs tə ðə ˈbeɪs/
  • need の d が tə に連結して [ˈnidə]
  • close の z が the の ə に連結 [ˈkloʊzə]（最初の close は動詞形）
  • 後の close は形容詞形 /ˈkloʊs/（無声音で s）
