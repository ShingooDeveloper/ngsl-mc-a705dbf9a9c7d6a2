ethics

名詞/ˈɛθɪks/CEFR B1英検準1級 #1116
  1. 【名詞】道徳原則、倫理観。ゲーム内で正当で公正なプレイの原則（…player ethics…）
  2. 【名詞】人の行動や決定を導く道徳的な原則や基準（…building ethics…）
  3. 【名詞】特定の職業や状況における行動規範（…Minecraft server ethics…）

⛏️ マインクラフト例文

⛏We follow strict ethics when building on the shared base.

私たちは共有ベースに建築する際、厳格な倫理規範に従っています。

/wi ˈfɑloʊ strɪkt ˈɛθɪks wɛn ˈbɪldɪŋ ɑn ðə ˈʃɛɹd beɪs/
  • strict ethics → 語末子音 /t/ が母音 /ɛ/ に連結 [strɪktɛθɪks]→ストリク・テシックス
  • building on → 語末鼻音 /ŋ/ が母音 /ɑ/ に連結 [ˈbɪldɪŋɑn]→ビルディン・オン
  • the shared → 冠詞 the は弱形 /ðə/ に弱化 [ðə]→ザ
ウィ フォロウ ストリク・テシックス ウェン ビルディン・オン ザ シェアド ベイス

⛏The server ethics prohibit griefing other players' creations.

サーバーの倫理規範は、他のプレイヤーの建造物を荒らすことを禁止しています。

/ðə ˈsɝvɚ ˈɛθɪks pɹoʊˈhɪbɪt ˈɡɹifɪŋ ˈʌðɚ ˈpleɪɚz kɹiˈeɪʃənz/
  • The server → 冠詞 the は弱形 /ðə/ に弱化 [ðə]→ザ、続く /s/ は連結不成立（子音+子音）
  • server ethics → 語末子音 /r/ が母音 /ɛ/ に連結 [ˈsɝvɚɛθɪks]→サーヴァ・エシックス
  • prohibit griefing → 語末 /t/ 未開放のまま次の子音 /ɡ/ に続く [pɹoʊˈhɪbɪt̚ ˈɡɹifɪŋ]→プロウヒビッ・グリーフィング
ザ サーヴァ・エシックス プロウヒビッ・グリーフィング アザー プレイヤーズ クリエイションズ

⛏Some players question the ethics of using mods in survival mode.

一部のプレイヤーは、サバイバルモードでMODを使用することの倫理を問い直しています。

/səm ˈpleɪɚz ˈkwɛsʃən ðə ˈɛθɪks əv ˈjuzɪŋ mɑdz ɪn sɚˈvaɪvəl moʊd/
  • the ethics → 冠詞 the は弱形 /ðə/；続く母音 /ɛ/ により schwa 削減 [ðɛθɪks]→ザ・エシックス
  • of using → 前置詞 of は弱形 /əv/ に弱化 [əvˈjuzɪŋ]→アヴ・ユージング
サム プレイヤーズ クエスチャン ザ・エシックス アヴ・ユージング マッズ イン・サーヴァイヴァル モウド
