allegation

名詞/ˌæl.ə.ˈɡeɪ.ʃən/CEFR B1英検準1級 #2273
  1. 【名詞】不正・違法な行為について根拠が明確でない主張・申し立て（…that...、...of...）
  2. 【名詞】告発・告白・申し出（…against...）
  3. 【名詞】根拠なき疑いや非難（unproven claim）

⛏️ マインクラフト例文

⛏There's an allegation that someone used creative mode to build the castle.

誰かがクリエイティブモードで城を建てたという告発がある。

/ðɛrz ən ˌæl.ə.ˈɡeɪ.ʃən ðæt ˈsʌm.wən ˈjuːzd kriˈeɪ.tɪv ˈmoʊd tə ˈbɪld ðə ˈkæs.əl/
  • There's an → There's の語末 /z/ が an の /ə/ に連結 [ðɛrz ən] ザーズ アン
  • allegation that → allegation の語末 /ən/ が consonant /ð/ に続くため連結なし。that は通常形
  • mode to → mode の語末 /d/ が to の弱形 /tə/ に連結 [ˈmoʊd tə] モード ター
ザーズ アン アレゲイション ザット サムワン ユーズド クリエイティヴ モード トゥ ビルド ザ キャッセル

⛏Allegation of cheating circulated through the server community.

チート行為の告発がサーバーコミュニティを通じて広がった。

/ˌæl.ə.ˈɡeɪ.ʃən əv ˈtʃiː.tɪŋ ˈsɝ.kjə.leɪ.tɪd θruː ðə ˈsɝ.vər kəˈmju.nə.ti/
  • Allegation of → Allegation の語末 /ən/ が of の弱形 /əv/ に連結 [ən əv] エン アヴ
  • circulated through → circulated の語末 /d/ が through の /θ/ に続く。子音なので連結なし
  • the server → the は弱形 /ðə/、server の /ˈsɝ.vər/ に続く [ðə ˈsɝ.vər] ザ サーバー
アレゲイション アヴ チーティング サーキュレイティド スルー ザ サーバー コミュニティ

⛏Despite the allegations against him, he continued playing fairly.

彼に対する告発があるにもかかわらず、彼は公正なプレイを続けた。

/dɪˈspaɪt ðə ˌæl.ə.ˈɡeɪ.ʃənz əˈɡɛnst hɪm hi kənˈtɪn.juːd ˈpleɪ.ɪŋ ˈfɛr.li/
  • Despite the → Despite の語末 /t/ は未開放 [dɪˈspaɪt̚]、the は弱形 /ðə/ で子音なので連結なし [ˈspaɪt̚ ðə] スパイッ ザ
  • allegations against → allegations の語末 /z/ が against の /ə/ に連結 [ˌæl.ə.ˈɡeɪ.ʃənz əˈɡɛnst] アレゲイションズ アゲンスト
  • playing fairly → playing の語末 /ŋ/ が fairly の /f/ に続く。子音なので連結なし [ˈpleɪ.ɪŋ ˈfɛr.li] プレイング フェアリー
ディスパイッ ザ アレゲイションズ アゲンスト ヒム ヒー コンティニューd プレイング フェアリー

/ðə ˈpleɪ.ər dɪˈnaɪd ˌæl.ə.ˈɡeɪ.ʃənz ðæt hi wəz ˈju.zɪŋ hæks tə ˈsiː θruː ˈwɔlz/
  • player denied → player の語末 /r/ が denied の /d/ に続く。子音なので連結なし
  • allegations that → allegations の語末 /z/ が that の /ð/ に連結 [ˌæl.ə.ˈɡeɪ.ʃənz ðæt] アレゲイションズ ザット
