input

名詞・動詞/ˈɪnpʊt/CEFR B1頻度#2076
  1. 【名詞】（コンピュータやマシンへの）入力、入力されるデータ・信号（…input data, input signal）
  2. 【名詞】（生産に必要な物質・エネルギー・労働などの）投入、投入量（…energy input, labor input）
  3. 【名詞】意見・提案・見解（…input from the team）
  4. 【動詞】（データ・情報を）入力する、打ち込む（…input a command）
  5. 【動詞】（意見や提案を）述べる、言う、提供する（…input thoughts on a design）
