following

形容詞・動詞・名詞/ˈfɑloʊɪŋ/CEFR B1ターゲット1200 #1502ターゲット中学1800 #987
  1. 【形容詞】次に述べる、次の、以下の（直後に続く）
  2. 【動詞】～に従う、～について来る、～を追う（～に沿って進む）
  3. 【名詞】フォロワー、支持者、信奉者（ある人物や運動の支持者たち）

⛏️ マインクラフト例文

⛏The following tools are required for mining diamonds.

ダイヤモンド採掘に必要な以下のツール。

/ðə ˈfɑloʊɪŋ tulz ɑr rɪˈkwaɪɚd fɚ ˈmaɪnɪŋ ˈdaɪmənz/
  • the → 機能語は弱形 /ðə/ に弱化
  • tools are → 語末子音 /z/ が母音 /ɑ/ に連結 [tulz ɑr]
  • for → 機能語は弱形 /fɚ/ に弱化
ザ ファロウィング トゥルズ アー リクワイアード ファー マイニング ダイモンズ

⛏Following the path, I found a treasure chest.

その道をたどって、宝箱を見つけた。

/ˈfɑloʊɪŋ ðə pæθ aɪ ˈfaʊnd ə ˈtreʒər ˈtʃɛst/
  • the → 機能語は弱形 /ðə/ に弱化
  • found a → 語末子音 /d/ が母音 /ə/ に連結 [ˈfaʊnd ə]
  • a → 機能語は弱形 /ə/ に弱化
ファロウィング ザ パス アイ ファウンダ トレジャー チェスト

⛏Following the tutorial, I need a crafting table.

チュートリアルに従って、クラフティングテーブルが必要だ。

/ˈfɑloʊɪŋ ðə tuˈtɔːɾiəl aɪ ˈniːd ə ˈkræftɪŋ ˈteɪbəl/
  • the → 機能語は弱形 /ðə/ に弱化
  • need a → 語末子音 /d/ が母音 /ə/ に連結 [ˈniːd ə]
  • a → 機能語は弱形 /ə/ に弱化
ファロウィング ザ トゥートリアル アイ ニーダ クラフティング テーブル

following the tutorialチュートリアルに従う

⛏Following the tutorial, I learned how to craft a wooden pickaxe.

チュートリアルに従って、木製つるはしの作り方を学んだ。

/ˈfɑloʊɪŋ ðə tuˈtɔːɾiəl aɪ ˈlɚnd haʊ tə kræft ə ˈwʊdən ˈpɪkæks/
  • the → 機能語は弱形 /ðə/ に弱化
  • to craft → to は機能語で弱形 /tə/、語末の /t/ と craft の /k/ は連続する子音だが連結しない
  • a → 機能語は弱形 /ə/ に弱化

the following day翌日、その次の日

⛏We mined diamonds yesterday, and the following day we smelted the ore.

昨日ダイヤを採掘して、翌日その鉱石を精錬した。

/wi ˈmaɪnd ˈdaɪmənz ˈjɛstɚdeɪ ænd ðə ˈfɑloʊɪŋ ˈdeɪ wi ˈsmɛltɪd ðə ˈɔr/
  • the → 機能語は弱形 /ðə/ に弱化（×2回）
  • and → 機能語は弱形 /ənd/ または /ən/
  • day we → /eɪ/ + /w/ で連結可能だが、複数形のため /z/ との連結はない
