command

名詞・動詞/kəˈmænd/CEFR B1頻度#1711
  1. 【名詞】指示、命令（an order given to someone to do something）
  2. 【名詞】（コンピュータ・ゲームの）コマンド、指令（a request to a computer or game to perform an action）
  3. 【動詞】命じる、統制する、支配する（to give an order to someone or have authority over）
