rain

名詞・動詞/reɪn/CEFR A1頻度#1229
  1. 【名詞】雨。空から降る水（…heavy rain）
  2. 【動詞】雨が降る。降雨する（…It rains）
  3. 【名詞】降水。雨の期間（…during the rain）

⛏️ マインクラフト例文

⛏We need a shelter before it rains.

雨が降る前に避難所が必要です。

/wiː ˈniːd ə ˈʃɛltər bɪˈfɔɹ ɪt ˈreɪnz/
  • d-ə 連結（need + a）
  • before の r-coloring
  • it の /t/ 未開放
ウィー・ニーダ・シェルター・ビフォア・イッ・レインズ

⛏When it rains, mobs spawn more often.

雨が降ると、敵モブがもっとよくスポーンします。

/wɛn ɪt ˈreɪnz moʊbz ˈspɔn mɔɹ ˈɔfən/
  • it の /t/ 未開放
  • more の r-coloring
ウェニッ・レインズ・モウブズ・スポーン・モア・オフン

⛏Rain makes dirt turn to mud on my farm.

雨は土を泥に変えます。私の農場では。

/ˈreɪn meɪks dɝt tɝn tə ˈmʌd ɑn maɪ ˈfɑɹm/
  • turn + to (weak) の n-ə 連結→ターナ
  • on の weak form
  • dirt の r-coloring
レイン・メイクス・ダート・ターナ・マッド・アン・マイ・ファーム

/ˈmʌltɪpl̩ reɪnz ɪn səkˈsɛʃən ˈkɔzd ˈsɪriəs ˈflʌdɪŋ əˈraʊnd ðə beɪs/
