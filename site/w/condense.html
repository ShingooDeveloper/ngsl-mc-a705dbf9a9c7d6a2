condense

動詞/kənˈdens/CEFR B2英検準1級 #681
  1. 【動詞】（文章・情報などを）凝縮する、要約する（The developers condensed the tutorial into a few simple pages. 開発者たちはチュートリアルを数ページの簡潔な内容に凝縮した。）
  2. 【動詞】（気体・液体などが）濃くなる、液化する（Water vapor condenses into liquid when cooled. 水蒸気は冷えると液化する。）
  3. 【動詞】圧縮する、詰める（We need to condense more blocks into this small build area. この狭い建築スペースにもっとたくさんのブロックを詰め込む必要があります。）
  4. 【動詞】（時間・空間を）短くまとめる（Players condensed weeks of building into a single night with the help of friends. プレイヤーたちは友人の助けを借りて数週間分の建築を1晩で圧縮した。）
