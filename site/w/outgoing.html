outgoing

形容詞・名詞/aʊtˈɡoʊɪŋ/CEFR B1英検準1級 #1717
  1. 【形容詞】(人が)社交的な、外向的な、人付き合いの良い（…He has an outgoing personality）
  2. 【形容詞】(郵便・便・通話など)発送される、発信される、出ていく（…outgoing mail）
  3. 【名詞】支出、出費（…monthly outgoings）

⛏️ マインクラフト例文

⛏Our outgoing admin started a community Discord server for everyone.

社交的な管理者が、みんなのためにコミュニティ用のDiscordサーバーを立ち上げた。

/ˈaʊər ˈaʊtɡoʊɪŋ ˈædmɪn ˈstɑrtəd ə kəˈmjunəti ˈdɪskɔrd ˈsɜrvər fər ˈɛvriˌwʌn/
  • started a → /d/ が母音 /ə/ に連結 [ˈstɑrtɪdə]
  • for everyone → /r/ が /ɛ/ に連結 [fərˈɛvriˌwʌn]
アワー アウトゴーイング アドミン スターティダ コミューニティ ディスコード サーバー フォレヴリワン

⛏The outgoing shift logged off after finishing their mining quota.

出ていく班は、採掘ノルマを終えてログオフした。

/ðə ˈaʊtɡoʊɪŋ ˈʃɪft ˈlɔɡd ˈɔf ˈæftər ˈfɪnɪʃɪŋ ðɛər ˈmaɪnɪŋ ˈkwoʊtə/
  • the → 弱形 /ðə/
  • logged off → /d/ が母音 /ɔ/ に連結 [ˈlɔɡdɔf]、off は未開放 [f̚]
ザ アウトゴーイング シフト ロッグドオフ アフター フィニッシング ゼア マイニング クウォータ

⛏Server outgoings increased when we upgraded to better hosting.

ホスティングをアップグレードしたとき、サーバーの支出が増加した。

/ˈsɜrvər ˈaʊtɡoʊɪŋz ɪnˈkrist wɛn wi ˈʌpɡreɪdɪd tu ˈbɛtər ˈhoʊstɪŋ/
  • server outgoings → /r/ が /aʊ/ に連結 [ˈsɜrvərˈaʊtɡoʊɪŋz]
  • to better → to は弱形 /tə/ [tə ˈbɛtər]
  • better hosting → /r/ が /h/ に連結 [ˈbɛtərˈhoʊstɪŋ]
サーバー アウトゴーイングズ インクリースト ウェン ウィ アップグレイディッド トゥ ベター ホースティング

💬 よく使う熟語（マイクラ例文）

outgoing call(通話で) 発信通話、外へかける電話

⛏The server admin received an outgoing call from a player who wanted to report a bug.

サーバー管理者は、バグを報告したいプレイヤーからの発信通話を受け取った。

/ðə ˈsɜrvər ˈædmɪn rɪˈsivd ən ˈaʊtɡoʊɪŋ ˈkɔl frəm ə ˈpleɪər hu ˈwɑnɾɪd tu rɪˈpɔrt ə ˈbʌɡ/
  • received an → /d/ が母音 /ə/ に連結 [rɪˈsivdən]、an は弱形 /ən/
  • wanted → 語中の /t/ がフラップ [ɾ] に [ˈwɑnɾɪd]
  • to report → to は弱形 /tə/ [tə rɪˈpɔrt]
  • from a → 弱形 from /frəm/ と弱形 a /ə/ で流れる [frəmə ˈpleɪər]
ザ サーバー アドミン リシーヴダン アウトゴーイング コール フラマ プレイヤー フー ワンリッド トゥ リポート ア バグ

/ˈaʊər ɡɪld ˈlidər hæz ən ˈaʊtɡoʊɪŋ pɚˈsænəlɪti ðæt ˈbrɪŋz ˈpleɪərz təˈɡɛðər/

  • together → to 弱形 /tə/ [təˈɡɛðər]
