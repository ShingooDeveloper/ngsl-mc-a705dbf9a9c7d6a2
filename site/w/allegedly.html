allegedly

副詞/əˈlɛdʒədli/CEFR B1英検準1級 #2169
  1. 【副詞】疑われている、根拠なく言われている（…だと言われている；根拠は不明）
  2. 【副詞】伝えられるところでは、報告によると（…と報告されている）
  3. 【副詞】~だと主張されている、~と称される（…と言い張られている）

⛏️ マインクラフト例文

⛏He allegedly discovered an amazing structure yesterday.

彼は昨日素晴らしい建造物を発見したと言われています。

/hi əˈlɛdʒədli ˌdɪsˈkʌvɚd ən əˈmeɪzɪŋ ˈstɹʌktʃɚ ˈjɛstɚdeɪ/
  • discovered の語末子音 /d/ が an の初音 /ə/ に連結し [ˈkʌvɚdən] カヴァーダン
  • an は弱形 /ən/。amazing の初音 /ə/ に連結 [ən əˈmeɪ] アン アメイ
ヒー アレジェドリ ディスカヴァーダン アメイジング ストラクチャー イエスターデイ

⛏The admin team allegedly fixed all the lag issues.

管理者チームはすべてのラグ問題を修正したと言われています。

/ðə ˈædmɪn ˈtiːm əˈlɛdʒədli ˈfɪkst ɔl ðə ˈlæɡ ˈɪʃuːz/
  • the は弱形 /ðə/。admin の /æ/ に先行 [ðə ˈæd] ザ アド
  • team の語末子音 /m/ が allegedly の初音 /ə/ に連結 [ˈtiːm əˈlɛdʒ] ティーム アレジェドリ
  • fixed の語末子音 /t/ が all の初音 /ɔ/ に連結 [ˈfɪkstɔl] フィクストール
  • all の語末子音 /l/ が the の初音弱形 /ð/ に連結 [ɔlðə] オールザ
ザ アドミン ティーム アレジェドリ フィクストール ザ ラグ イシューズ

⛏They allegedly found a rare ore deposit near the spawn.

彼らはスポーン近くで希少鉱石の鉱脈を見つけたと言われています。

/ðeɪ əˈlɛdʒədli ˈfaʊnd ə ˈreɪr ɔr dɪˈpoʊzɪt nɪr ðə ˈspoʊn/
  • found の語末子音 /d/ が a の初音 /ə/ に連結 [ˈfaʊndə] ファウンダ
  • ore の語末子音 /r/ が deposit の初音 /d/ に未開放で連接 [ˈɔr‿d̚ dɪ] オアド ディ
  • deposit の語末子音 /t/ が near の初音 /n/ に未開放で連接 [zɪt̚ nɪr] ジット ニア
ゼイ アレジェドリ ファウンダ レア オアド ディポーズィット ニア ザ スポーン

💬 よく使う熟語（マイクラ例文）

allegedly used～を使ったと言われている、～で作ったと疑われている

⛏He was allegedly using Creative Mode to build that mansion.

彼がそのマンションを建てるのにクリエイティブモードを使ったと言われています。

/hi wəz əˈlɛdʒədli ˈjuːzɪŋ ˈkrɪeɪtɪv ˈmoʊd tə ˈbɪld ðæt mænˈʃən/
  • was は弱形 /wəz/。allegedly の /ə/ に先行 [wəz əˈlɛdʒ] ワズ アレジェドリ
  • to は弱形 /tə/。build の /b/ に連結 [tə ˈbɪld] タ ビルド
ヒー ワズ アレジェドリ ユージング クリエイティヴ モード タ ビルド ザット マンシャン
