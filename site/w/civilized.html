civilized

形容詞/ˈsɪvəlaɪzd/CEFR B1英検準2級 #541
  1. 【形容詞】文明的な、教養のある（…civilized society, civilized behavior…）
  2. 【形容詞】（土地や地域が）文明が発達した、開発された
  3. 【形容詞】（人の言動・態度が）礼儀正しい、上品な、洗練された

⛏️ マインクラフト例文

⛏We need a civilized city plan before building the town.

町を建築する前に、私たちは文明的な都市計画が必要です。

/wi ˈniːd ə ˈsɪvəlaɪzd ˈsɪti ˈplæn bɪˈfɔr ˈbɪldɪŋ ðə ˈtaʊn/
  • need a → 語末子音 /d/ が母音 /ə/ に連結 [ˈniːdə]（ニーダ）
  • city plan → city の /t/ は母音に挟まれてフラップ化し /ɾ/ に、plan の語末 /n/ が building の子音 /b/ の前で未開放 [ˈsɪɾi plæn̚]（シリ プラン）
  • plan building → plan の語末 /n/ が building の /b/ の前で未開放 [plæn̚ ˈbɪldɪŋ]（プラン・ビルディング）
ウィ ニーダ ア シビライズド シリ プラン ビフォー ビルディング ザ タウン

⛏This civilized architecture requires careful resource management.

この文明的な建築は注意深いリソース管理を必要とします。

/ðɪs ˈsɪvəlaɪzd ɑrˈkɪtɛktʃər rɪˈkwaɪərz ˈkeɹfəl ˈrɛsɔrs ˈmænɪdʒmənt/
  • This civilized → 語末子音 /s/ が civilized の /s/ の前で未開放 [ðɪs̚ ˈsɪvəlaɪzd]（ディス・シビライズド）
  • civilized architecture → 語末 /d/ が architecture の /ɑ/ に連結 [ˈsɪvəlaɪzd ɑr...]（シビライズド・アーキテクチャー）
  • requires careful → requires の語末 /z/ が careful の /k/ の前で未開放 [rɪˈkwaɪərz̚ ˈkeɹfəl]（リクワイアーズ・ケアフル）
ディス シビライズド アーキテクチャー リクワイアーズ ケアフル レソース マネージメント

⛏A civilized community has organized zones for mining and farming.

文明的なコミュニティは、採掘と農業のための整理されたゾーンを持っています。

/ə ˈsɪvəlaɪzd kəˈmjuːnəti hæz ˈɔrɡənaɪzd ˈzoʊnz fɔr ˈmaɪnɪŋ ənd ˈfɑrmɪŋ/
  • A civilized → 弱形 /ə/ が civilized の /s/ に続く [ə ˈsɪvəlaɪzd]（ア・シビライズド）
  • civilized community → civilized の語末 /d/ が community の /k/ の前で未開放 [ˈsɪvəlaɪzd̚ kəˈmjuːnəti]（シビライズド・コミュニティ）
  • has organized → has の語末 /z/ が organized の /ɔ/ に連結 [hæz ˈɔrɡənaɪzd]（ハズ・オーガナイズド）
