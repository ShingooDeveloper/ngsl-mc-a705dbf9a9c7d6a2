doubtfully

副詞/ˈdaʊtfəli/CEFR B1英検2級 #515
  1. 【副詞】疑わしげに、不信の態度で（～のことを）
  2. 【副詞】不確かに、確信なく、おぼつかなく
  3. 【副詞】（～が本当だろうか）懐疑的に、マイナス方向に

⛏️ マインクラフト例文

⛏I doubtfully took a map into the cave.

僕は疑わしげに地図を手に洞窟へ入った。

/aɪ ˈdaʊtfəli ˈtʊk ə ˈmæp ˈɪntu ðə ˈkeɪv/
  • took の語末 /k/ が弱形 /ə/ に連結 [ˈtʊkə]、『トゥッカ』
  • into の /tu/ は弱形 /tə/ に弱化、『イント』→『イナ』
  • the は子音前の弱形 [ðə]『ザ』。cave の /v/ に連結
アイ ダウトフェリ トゥッカ マップ イント ザ ケイヴ

⛏They doubtfully set out for the End.

彼らは疑わしげに『エンド』へ出かけた。

/ðeɪ ˈdaʊtfəli ˈsɛt ˈaʊt ˈfɔr ðə ˈɛnd/
  • set と out の語末 /t/ は次の /aʊ/ に続く際、unreleased [ˈsɛt̚] で区切られる
  • for『フォア』。the の弱形 /ðə/『ザ』
  • the と End の /ɛ/ は vowel-vowel で自然に流れる
ゼイ ダウトフェリ セッ アウト フォア ザ エンド

⛏We doubtfully got it from the Nether.

私たちは疑わしげにネザーからそれを手に入れた。

/wi ˈdaʊtfəli ˈɡɑt ɪt ˈfrɑm ðə ˈnɛðər/
  • got の /t/ は /ɪt/ の /ɪ/ に挟まれフラップT [ɾ]『ガリッ』。it の /t/ は未開放
  • from の語末 /m/ は子音 /ð/ の前で『フラム』。the の弱形 /ðə/『ザ』
  • Nether の /ðər/ は /ə/ + /r/ で『ザー』、弱形と rhotic
ウィ ダウトフェリ ガリッ フラム ザ ネザー
