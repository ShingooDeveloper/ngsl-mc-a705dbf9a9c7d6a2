console

名詞・動詞/kənˈsoʊl/CEFR B1ターゲット1900 #1703
  1. 【名詞】ビデオゲーム機器。PlayStation、Nintendo Switch など、テレビに接続してゲームをプレイするための専用端末（electronic gaming device）
  2. 【名詞】（Minecraft Java Edition）コマンド実行画面。チート機能やアドミニストレーション機能にアクセスするためのパネル（command interface for executing commands）
  3. 【名詞】操作パネル。ボタンやレバーなどのスイッチが集中している制御盤。レッドストーン回路などで利用される（control panel）
  4. 【動詞】〔人を〕慰める。落ち込んでいる人を励ましたり、心理的にサポートしたりする（to comfort someone）
