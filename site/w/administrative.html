administrative

形容詞/ˌæd.mɪn.ɪ.ˈstreɪ.tɪv/CEFR B2英検準1級 #1024
  1. 【形容詞】行政上の、管理に関する（administration に関連した）
  2. 【形容詞】実行上の、実務的な（practical management に関する）
  3. 【形容詞】事務的な、手続き的な（bureaucratic processes に関する）
  4. 【形容詞】（システムやサーバーの）管理・運営に関する

⛏️ マインクラフト例文

⛏We need administrative access to modify server settings.

サーバーの設定を変更するために、管理者アクセスが必要です。

/wij ˈniːd ˌæd.mɪn.ɪ.ˈstreɪ.tɪv ˈæk.sɛs tə ˈmɑd.ə.faɪ ˈsɝ.vɚ ˈsɛt.ɪŋz/
  • need の語末 /d/ が administrative の /æ/ に連結 [ˈniːd ˌæd] ニード アド
  • to の弱形 /tə/ [tə ˈmɑd] タ モディ
ウィ ニード アドミニストレイティヴ アクセス タ モディファイ サーバー セティングズ

⛏The server's administrative settings control mob spawning and difficulty.

サーバーの管理設定がモブの出現とゲーム難度を制御します。

/ðə ˈsɝ.vɚz ˌæd.mɪn.ɪ.ˈstreɪ.tɪv ˈsɛt.ɪŋz kənˈtroʊl ˈmɑb ˈspoʊ.nɪŋ ənd ˌdɪf.ɪˈkəl.ti/

インベントリ管理などの管理上のタスクは、綿密な計画が必要です。
