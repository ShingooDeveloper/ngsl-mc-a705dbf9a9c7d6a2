awesome

形容詞/ˈɔːsəm/CEFR A1英検3級 #702
  1. 【形容詞】素晴らしい、素敵だ、最高だ（大いに価値がある、感動的である）
  2. 【形容詞】敬畏の念や恐怖心を起こさせる、荘厳な
  3. 【形容詞】（非公式用法）非常に素晴らしい、とても素敵だ

⛏️ マインクラフト例文

⛏That build is awesome!

その建築は素晴らしい！

/ðæt bɪld ɪz ˈɔːsəm/
  • That の語末 /t/ が build の /b/ に子音+子音で続き、/t/ は未開放 [ðæt̚ bɪld]
  • build の語末 /d/ が is の /ɪ/ に連結 [bɪld ɪz]
  • is の語末 /z/ が awesome の /ɔ/ に連結 [ɪz ˈɔːsəm]
ザッビルディズオーサム

⛏These enchantments are awesome.

これらのエンチャントは素晴らしい。

/ðiz ɛnˈtʃɑntmənts ɑr ˈɔːsəm/
  • These の語末 /z/ が enchantments の /ɛ/ に連結 [ðiz ɛnˈtʃɑntmənts]
  • are の語末 /r/ が awesome の /ɔ/ に連結 [ɑr ˈɔːsəm]

⛏Awesome! I found diamonds.

最高だ！ダイヤモンドを見つけた。

/ˈɔːsəm aɪ ˈfaʊnd ˈdaɪmənz/
  • awesome の語末 /m/ が I の /aɪ/ に連結 [ˈɔːsəm aɪ]
  • found の語末 /d/ が diamonds の /d/ に未開放で続く [ˈfaʊnd̚ ˈdaɪmənz]
