pleased

形容詞/pˈlɛzd/CEFR B1ターゲット1200 #1307
  1. 【形容詞】喜んでいる、満足している（I'm pleased with the result / 結果に満足している）
  2. 【形容詞】喜んで～する、進んで～する（I'd be pleased to help / 喜んで手伝う）
  3. 【形容詞】うれしそうな、喜びに満ちた表情の（She looked pleased / 彼女はうれしそうに見えた）

⛏️ マインクラフト例文

⛏I'm really pleased with the new base we built.

私たちが建てた新しい基地に本当に満足しています。

/aɪm ˈɹɪli pˈlɛzd wɪð ðə nju beɪs wi bɪlt/
  • with the → /ð/の同音融合で [wɪðə]
アイム・リリー・プレズド・ウィズ・ザ・ニュー・ベイス・ウィ・ビルト

⛏I'd be pleased to help you gather resources.

喜んであなたが資源を集めるのを手伝います。

/aɪd bə pˈlɛz̚tə ˈhɛlpjə ˈɡæðɚ ɹɪˈsoɹsɪz/
  • pleased to → /d/が/t/に続く。未開放で [pˈlɛz̚ə]
  • help you → 語末/p/から/j/へ連結 [ˈhɛlpjə]
  • be pleased → 「be」は弱形/bə/に弱化 [bə pˈlɛzd]
アイド・バ・プレズア・ヘルプユ・ギャザー・リソーシズ

⛏They were pleased when they discovered the cave system.

彼らは洞窟システムを発見したときに満足していました。

/ðə wə pˈlɛzd wɛn ðə dɪˈskʌvɚd ðə keɪv ˈsɪstəm/
  • They were → 両方が弱形に。「They」/ðə/、「were」/wə/ [ðə wə]
  • when they → /n/から弱形/ðə/へ連結 [wɛn ðə]
  • 複数の「the」→ すべて弱形/ðə/で「ザ」と発音
ザ・ワ・プレズド・ウェン・ザ・ディスカヴァード・ザ・ケイヴ・システム
