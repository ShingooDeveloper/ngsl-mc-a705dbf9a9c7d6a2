bus

名詞・動詞/bʌs/CEFR A1頻度#809
  1. 【名詞】乗客を運ぶ大型の自動車（…public transport…）
  2. 【名詞】複数のデバイスを接続する電子部品（…data bus…）
  3. 【名詞】マインクラフトで複数の場所をつなぐ輸送・信号システム
  4. 【動詞】バスで旅行する
  5. 【動詞】北米：テーブルから食器を片付ける（…clear dishes…）

⛏️ マインクラフト例文

⛏We need a bus system to automate farming.

ファーミング自動化のためにバスシステムが必要だ。

/wi niːd ə bʌs ˈsɪs.təm tə ɔˈtɑm.eɪt ˈfɑrm.ɪŋ/
  • need の語末子音 /d/ が a の母音 /ə/ に連結 [niːdə]
  • to は機能語で弱形 /tə/ に弱化 [tə] タ
ウィ ニーダ バス システム タ オートメイト ファーミング

⛏Run it quickly using the bus system.

  • is busing → is は弱形 /ɪz/、/z/ + /b/ (consonant+consonant、連結なし)
