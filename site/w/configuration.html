configuration

名詞/ˌkɑnfɪɡjəˈreɪʃən/CEFR B1英検準1級 #3291
  1. 【名詞】機械やシステムの部品・要素の配置・組み合わせ方（the arrangement of parts in a device or system）
  2. 【名詞】コンピュータやソフトウェアの設定・構成（the settings or setup of a computer system or software）
  3. 【名詞】特定の方法で組織・配置されたもの、構成（the way something is arranged or organized）

⛏️ マインクラフト例文

⛏This redstone configuration takes a while to build.

このレッドストーン配置は完成に時間がかかります。

[ðɪs ˈɹɛdˌstoʊn ˌkɑnfɪɡjəˈreɪʃən ˈteɪksə ˈwaɪl tə ˈbɪld]
  • takes a: 語末子音 /s/ が母音 /ə/ に連結 [ˈteɪksə]→「テイクサ」
  • to: 弱形 /tə/→「タ」
ディス レッドストウン コンフィギュレーション テイクサ ワイル タ ビルド

⛏Change the configuration if you want a different look.

別の見た目がほしいなら配置を変えてください。

[tʃeɪndʒə ðə ˌkɑnfɪɡjəˈreɪʃən ɪf juː ˈwɑn tə ˈdɪfəɹənt ˈlʊk]
  • if you: 語末子音 /f/ が母音 /ju/ に連結 [ɪf juː]→「イフユー」
  • want a: 語末子音 /t/ が母音 /ə/ に連結 [ˈwɑn tə]→「ワンタ」
チェンジア ザ コンフィギュレーション イフユー ワンタ ディファレント ルック

⛏The armor configuration needs protective boots.

その防具構成には保護靴が必要です。

[ðə ˈɑɹmɚ ˌkɑnfɪɡjəˈreɪʃən ˈniːdz̚ prəˈtɛktɪv ˈbuːts]
  • needs protective: needs の語末 /z/ は未開放で、protective の /p/ に先立つ [ˈniːdz̚ prəˈtɛktɪv]→「ニーズ プロテクティブ」
ザ アーマー コンフィギュレーション ニーズ プロテクティブ ブーツ
