disdain

名詞・動詞/dɪzˈdeɪn/CEFR B2英検準1級 #2292
  1. 【名詞】軽蔑や嫌悪の感情。相手を見下す態度（…with disdain のような用例で）
  2. 【名詞】〜に対する見下し・軽蔑（…disdain for のような構造で）
  3. 【動詞】〜を軽蔑する・見下す。人や行動に対して尊重を示さない

⛏️ マインクラフト例文

⛏She disdains everyone who breaks any shared server rules.

彼女は、共有サーバーのルールを破る者を誰でも軽蔑している。

[ʃi dɪzˈdeɪnz ˈɛvɹiˌwʌn ˈhu ˈbreɪks ˈɛni ˈʃɛɹd ˈsɚvɚ ˈɹuːlz]
  • disdains everyone → /z/ (disdains の末尾) が母音 /ɛ/ に連結 [dɪzˈdeɪnz ɛvɹiˌwʌn] ディズデイン エブリワン
  • breaks any → /s/ (breaks の末尾の子音 /ks/ における最後の音) が母音 /ɛ/ に連結 [ˈbreɪksɛni] ブレイクセニ
  • who breaks → /u/ (who の末尾は /u/ 母音) と /b/ (breaks の頭)。母音+子音なので連結なし
シー ディズデイン エブリワン フー ブレイクセニ シェアド サーバー ルーズ

⛏The expert player made it obvious she felt disdain for everyone.

その熟練プレイヤーは、皆に対する軽蔑を感じていることが明らかだった。

[ðə ˈɛkspɚt ˈpleɪɚ ˈmeɪd ɪt ˈɑbviəs ʃi ˈfɛlt dɪzˈdeɪn ˈfɔɹ ˈɛvɹiˌwʌn]
  • made it → 語末子音 /d/ が母音 /ɪ/ に連結、またはフラップ化 [ˈmeɪɾɪt] メイリッ
  • it obvious → 語末子音 /t/ が母音 /ɑ/ に連結、未開放状態で [ɪt̚ ˈɑbviəs] イッ オブビアス
  • felt disdain → /t/ が未開放で次の子音 /d/ に連接 [ˈfɛlt̚ dɪzˈdeɪn] フェッ ディズデイン
ザ エクスパート プレイヤー メイド イッ オブビアス シー フェッ ディズデイン フォー エブリワン

⛏Many hardcore players hold an intense disdain for server rules.

多くのハードコアプレイヤーはサーバールールに対して激しい軽蔑を抱いている。

[ˈmɛni ˈhɑɹdˌkoɹ ˈpleɪɚz ˈhoʊld ən ɪnˈtɛns dɪzˈdeɪn ˈfɔɹ ˈsɚvɚ ˈɹuːlz]
  • hold an → 語末子音 /d/ が弱形 an の母音 /ə/ に連結、フラップ化 [ˈhoʊɾən] ホウラン
  • an intense → /n/ (an の末尾) が母音 /ɪ/ (intense の頭) に連結 [ən ɪnˈtɛns] エン インテンス
  • for server → /ɹ/ は音節末の r 音で、server の /s/ は子音。子音+子音なので連結なし
メニ ハードコア プレイヤーズ ホウラン インテンス ディズデイン フォー サーバー ルーズ

⛏The veteran player treated the mod-users with obvious disdain.

その熟練プレイヤーはmod使用者たちを明らかに軽蔑して扱った。

[ðə ˈvɛtɚən ˈpleɪɚ ˈtɹɪtɪd ðə ˈmɑdˌjuːzɚz wɪð ˈɑbviəs dɪzˈdeɪn]

  • with obvious → /θ/ (with の末尾) が母音 /ɑ/ に連結 [wɪθ ˈɑbviəs] ウィズ オブビアス
  • obvious disdain → /s/ が子音 /d/ に… 子音+子音なので連結なし
ザ ヴェテラン プレイヤー トゥリティド ザ モド ユーザーズ ウィズ オブビアス ディズデイン
