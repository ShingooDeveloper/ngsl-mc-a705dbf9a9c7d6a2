ramp

名詞・動詞/ræmp/CEFR B1英検準1級 #2399
  1. 【名詞】傾斜路、斜面（高低差をなめらかに解消し登降や移動を容易にする）
  2. 【名詞】スロープ、坂道（建築物や構造物に接続する傾斜した面）
  3. 【動詞】急速に増加させる、段階的に上昇させる（通常 up と共に ramp up の形で使う）

⛏️ マインクラフト例文

⛏We need a ramp for the minecart track.

ミニカートのレール用の斜面が必要です。

[wiː ˈniːdə ræmp fɔr ðə ˈmaɪn kɑɹt træk]
  • need a: 語末子音 /d/ が母音 /ə/ に連結 [ˈniːdə] ニーダ。a は弱形 /ə/
  • ramp for: ramp の語末 /p/ が for の /f/ に続く（子音+子音なので連結なし）[ræmp fɔr] ラムプ フォー
  • for the: for の語末 /r/（流音）。the の弱形 /ðə/ に先行（子音+子音なので連結なし）[fɔr ðə] フォー ザ
  • minecart track: minecart の語末 /t̚/（未開放）が track の /t/ に続く（未開放+開放で1つの /t/ に聞こえる）[ˈmaɪn kɑɹt̚ ˈtræk] マイン カート トラック
ウィー ニーダ ラムプ フォー ザ マイン カート トラック

⛏Build a ramp to access the upper level.

上階にアクセスするための斜面を作ります。

[ˈbɪldə ræmp tə ækˈsɛs ðə ˈʌp ɚ ˈlɛv əl]
  • build a: 語末子音 /d/ が母音 /ə/ に連結 [ˈbɪldə] ビルダ。a は弱形 /ə/
  • a ramp: a は弱形 /ə/ で終わる。ramp は /ræmp/ で始まるため、特に音の変化は起こらない [ə ræmp] ア ラムプ
  • ramp to: ramp の語末 /p/ が to の /t/ に続く（子音+子音なので連結なし）[ræmp tə] ラムプ タ。to は機能語で弱形 /tə/
  • to access: to の弱形 /tə/ が access の /æ/ に先行。access は動詞で第2音節にストレス [tə ækˈsɛs] タ アクセス
  • the upper: the は弱形 /ðə/。upper の /ʌ/ に先行 [ðə ˈʌp ɚ] ザ アッパー
ビルダ ラムプ タ アクセス ザ アッパー レベル

⛏Ramp up production of enchanted books.

エンチャント本の生産を増やす。

[ræmp ʌp prəˈdʌk ʃən əv ɪnˈtʃæn təd ˈbʊks]
  • ramp up: ramp の語末 /p/ が up の /ʌ/ に続く。子音+母音のため連結は起こらない [ræmp ʌp] ラムプ アップ
  • up production: up の /p/ が production の /p/ に続く（子音+子音なので連結なし）[ʌp prəˈdʌkʃən] アップ プロダクション
  • production of: production の語末 /n/ が of の /ə/ に連結 [ʃən əv] シェン アヴ。of は弱形 /əv/
  • of enchanted: of の /v/ が enchanted の /ɪ/ に連結 [əv ɪnˈtʃændəd] アヴ インチャンテッド
  • enchanted books: enchanted の語末 /d/ が books の /b/ に連結 [ˈtʃændəd ˈbʊks] エンチャンテッド ブックス
ラムプ アップ プロダクション アヴ インチャンテッド ブックス

⛏We need to ramp up ore production to build the new base.

新しい拠点を建設するための鉱石生産を増やす必要があります。

[wiː ˈniːd tə ræmp ʌp ˈɔr prəˈdʌkʃən tə ˈbɪld ðə ˈnjuː ˈbeɪs]
  • need to: need の語末 /d̚/（未開放）が to の /t/ に続く [ˈniːd̚ tə] ニード タ
  • ramp up: ramp の語末 /p/ が up の /ʌ/ に続く。子音+母音のため連結は起こらない [ræmp ʌp] ラムプ アップ
  • up ore: up の /p/ が ore の /ɔ/ に続く。子音+母音のため連結は起こらない [ʌp ˈɔr] アップ オア
  • production to: production の語末 /n̚/（未開放）が to の /t/ に続く [ʃən tə] シェン タ
  • the new: the は弱形 /ðə/。new の /n/ に先行 [ðə ˈnjuː] ザ ニュー
  • new base: new の /uː/ が base の /b/ に先行。子音+母音のため連結は起こらない [ˈnjuː ˈbeɪs] ニュー ベイス
