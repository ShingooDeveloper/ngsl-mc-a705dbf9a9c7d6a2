utterance

名詞/ˈʌtɚəns/CEFR B2英検準1級 #1448
  1. 【名詞】音声で発せられた一つの発言や言葉。発話（a spoken statement or remark; something said）
  2. 【名詞】発言の行為。話すこと；音声で表現されたもの（the act of uttering or speaking; vocal expression）
  3. 【名詞】発言された内容全体。明確に聞こえる言葉や音（a unit of speech; words that are clearly heard）

⛏️ マインクラフト例文

⛏Listen carefully to every utterance the elder gives before accepting a new quest.

新しいクエストを受け入れる前に、長老が言うあらゆる発言を注意深く聞いてください。

[ˈlɪs.ən ˈkeɚ.fə.li tu ˈɛv.ɹi ˈʌɾ.ɚ.əns ðə ˈɛl.dɚ ɡɪvz bɪˈfoɹ əkˈsɛp.tɪŋ ə ˈnu kwɛst]
  • listen → 語末の /n/ が未開放で [ˈlɪs.ən̚]；to が弱形 /tə/ に弱化
  • the elder → the が弱形 /ðə/；語末の /ə/ が elder の /ɛ/ に連結
  • gives before → gives の語末 /z/ が before の子音 /b/ に先行

⛏The warden's menacing utterance echoed through the deep dark.

ウォーデンの脅迫的な発声は、ディープダークに響き渡りました。

[ðə ˈwɔɹ.dənz məˈnæs.ɪŋ ˈʌɾ.ɚ.əns ˈɛk.oʊd θɹu ðə ˈdip dɑɹk]
  • the → 弱形 /ðə/；warden's の語末 /z/ が the の /ə/ に連結
  • menacing utterance → menacing の語末 /ŋ/ が utterance の /ʌ/ に連結（鼻音は子音として機能）
  • echoed through → echoed の語末 /d/ が未開放で [d̚]；through の /θ/ に先行
  • the deep dark → the が弱形 /ðə/；deep の語末 /p/ と dark の /d/ は子音クラスタ

⛏Every utterance in the server chat must follow community guidelines.

サーバーチャット内のあらゆる発言はコミュニティガイドラインに従う必要があります。

[ˈɛv.ɹi ˈʌɾ.ɚ.əns ɪn ðə ˈsɝv.ɚ tʃæt mʌst ˈfɑl.oʊ kəˈmju.nə.ti ˈɡaɪd.laɪnz]
  • in the → 語末 /n/ が the の /ð/ に先行；the は弱形 /ðə/
  • server chat → server の語末 /ɚ/ が chat の /tʃ/ に連結
  • chat must → chat の語末 /t/ が未開放で [tʃæt̚]；must の /m/ に先行
