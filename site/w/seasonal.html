seasonal

形容詞/ˈsiːzən.əl/CEFR B1ターゲット1900 #1191
  1. 【形容詞】特定の季節に起こる、特定の季節に関連する（seasonal changes = 季節変化）
  2. 【形容詞】季節に応じて変わる、周期的な（seasonal pattern = 季節パターン）
  3. 【形容詞】季節限定的な、期間限定の（seasonal work = 季節労働）
  4. 【形容詞】特定の季節に多く採掘・入手できる、季節産のような（seasonal crops = 季節作物）
