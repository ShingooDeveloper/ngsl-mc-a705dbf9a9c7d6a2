if

接続詞/ɪf/CEFR A1頻度#33NGSLターゲット中学1800 #76英検3級 #216
  1. 【接続詞】～であれば、～ならば、もし～（条件を導入）
  2. 【接続詞】～かどうか、～であるか否か（間接疑問）

⛏️ マインクラフト例文

⛏If you see a creeper, run!

クリーパーを見かけたら、逃げろ！

[ɪfjuː siːə ˈkriːpər rʌn]
  • If you: 子音クラスタ /fj/ で続く [ɪfjuː] イフユ
イフユ シア クリーパー ラン

⛏If I collect enough obsidian, I'll build a Nether portal.

黒曜石をたくさん集めたら、ネザーゲートを作るつもり。

[ɪfaɪ kəˈlɛkt ɪˈnʌf ɑbˈsɪdiən aɪl ˈbɪld ə ˈnɛðɚ ˈpɔːrtəl]
  • If I: /f/ が /aɪ/ に連結して [ɪfaɪ] イファイ
  • collect enough: /t/ が /ɪ/ に続き [kəˈlɛkt ɪˈnʌf] コレクト イナフ
イファイ コレクト イナフ アプシディアン アイル ビルド ア ネザー ポータル

⛏I'm checking if this biome is safe for a base.

このバイオームがベースに安全かどうか、確認中。

[aɪm ˈtʃɛkɪŋ ɪf ðɪs ˈbaɪoʊm ɪz seɪf fər ə ˈbeɪs]
  • I'm: 縮約で /m/ が続く [aɪm] アイム
  • safe for: /f/ が重なり [seɪf fər] セイフ ファ（for は弱形）
  • a base: a は弱形 /ə/ で /b/ に続く [ə ˈbeɪs] ア ベイス
アイム チェッキング イフ ジス バイオーム イズ セイフ ファ ア ベイス

⛏The ghast moved as if it detected us.

ガストは、まるで私たちを検出したかのように動いた。

[ðə ɡɑːst ˈmuːvd æzɪf ɪt̚ dɪˈtɛktəd ʌs]

  • it detected: /t/ が未開放で [ɪt̚ dɪˈtɛktəd] イット ディテクテッド

as if [though]まるで…であるかのようにターゲット1200 #1675

⛏The zombie moves as if it can see us through the wall.

そのゾンビは、まるで壁越しに私たちが見えているかのように動く。

/ðə ˈzɑmbi muvz æz ɪf ɪt kæn si əs θru ðə wɔl/

  • as if → 語末子音 /z/ が母音 /ɪ/ に連結 [æzɪf] アズィフ
  • if it → 語末子音 /f/ が母音 /ɪ/ に連結 [ɪfɪt] イフィット

⛏If it were not for my pickaxe, I couldn't mine the obsidian.

[ɪf ɪt̚wɚ nɑt̚ fɚ maɪ ˈpɪkæks | aɪ ˈkʊdənt maɪn ðə əbˈsɪdiən]
  • it were — /t/ が未開放で次の /w/ に連接 [ɪt̚wɚ] イッワー

as if/though …まるで…するように、あたかも…かのようにターゲット1000 #178

⛏The creeper moved slowly as if it hadn't noticed me yet.

クリーパーはまだ私に気づいていないかのように、ゆっくり動いていた。

/ðə ˈkripər ˈmuvd ˈsloʊli æzɪfɪt̚ ˈhædn̩t ˈnoʊɾɪst mi jɛt/
  • the → 機能語は弱形 /ðə/
  • as if → as の語末子音 /z/ が if の母音 /ɪ/ に連結 [æzɪf] アズィフ
  • if it → if の語末子音 /f/ が it の母音 /ɪ/ に連結し、it の語末 /t/ は未開放 [ɪfɪt̚] イフィット
  • noticed → /oʊ/ と /ɪ/ の間の /t/ がフラップ /ɾ/ に変わり [ˈnoʊɾɪst] ノウリスト
