kick

動詞・名詞/kɪk/CEFR A1頻度#1727
  1. 【動詞】足で蹴る、蹴撃を加える（kick a mob など）
  2. 【動詞】（ゲームサーバーから）追放する、除外する（kick a player など）
  3. 【名詞】蹴り、足による一撃（That kick was perfect など）

⛏️ マインクラフト例文

⛏I kick the creeper before it explodes.

クリーパーが爆発する前に蹴り飛ばします。

/aɪ ˈkɪk ðə ˈkriːpər bɪˈfɔrɪt ɪɾɪkˈsploʊdz/
  • the は機能語で弱形 /ðə/ に弱化 [ðə] → ザ
  • before の語末 /r/ が it の /ɪ/（母音）に連結 [ˈfɔrɪt] → フォーリット
  • it の語末 /t/ が explodes の /ɪ/（母音）に挟まれてフラップ化 [ɪɾɪk] → イリク
アイ キック ザ クリーパー ビフォーリット イリクスプロウズ

⛏The server admin kicks out griefers.

/ðə ˈsɝvər ˈædmɪn ˈkɪks ˈaʊt̚ ˈɡriːfərz/
  • the は機能語で弱形 /ðə/ に弱化 → ザ
  • out の語末 /t/ が griefers の /ɡ/（子音）に続く場合、/t/ は未開放 [ˈaʊt̚ ɡ] → アウッ
ザ サーバー アドミン キックス アウッ グリーファーズ

⛏That kick was perfect!

その蹴りは完璧だった！

/ðæt̚ ˈkɪk wəz ˈpɝfɪkt/
  • That の語末 /t/ が kick の /k/（子音）に続く場合、/t/ は未開放 [ðæt̚ kɪk] → ザッキック
  • was は弱形 /wəz/ に弱化 → ワズ
ザッ キック ワズ パーフィクト
