regime

名詞/rəˈʒiːm/CEFR C1ターゲット1900 #1756
  1. 【名詞】政治体制・統治形態（政府または統治者による支配、またはそれが続く期間）
  2. 【名詞】制度・体系（規律正しく実行される一連の行為・方法・習慣）

⛏️ マインクラフト例文

⛏The server admin established a strict regime to prevent griefing and theft.

サーバー管理者は、グリーフィングや盗難を防ぐための厳しい体制を確立した。

/ðə ˈsɝvɚ ˈædmɪn ɪˈstæblɪʃt ə ˈstrɪkt rəˈʒiːm tə prɪˈvɛnt ˈɡriːfɪŋ ən ˈθɛft/
  • admin の末尾 /n/ が established の /ɪ/ に連結 [ˈædmɪn ɪ] → アドミン イ
  • regime の末尾 /m/ が to の /t/ に先行、t は未開放 [rəˈʒiːm̚ tə] → レジーム タ
  • prevent の末尾 /t/ は未開放、griefing の /ɡ/ に先行 [prɪˈvɛn̚t ɡ] → プリベント グ

⛏My mining regime requires collecting 64 diamonds before I expand the base.

私の採掘体系では、基地を拡張する前に64個のダイヤモンドを集める必要があります。
