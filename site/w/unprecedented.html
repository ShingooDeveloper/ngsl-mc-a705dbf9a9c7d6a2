unprecedented

形容詞/ʌnˈprɛsədəntɪd/CEFR C1ターゲット1900 #1380英検準1級 #2354
  1. 【形容詞】かつてない、前例がない（unprecedented victory in PvP）
  2. 【形容詞】比類のない、並ぶもののない（unprecedented scale of the mega-base）
  3. 【形容詞】前代未聞の、前無比の（unprecedented number of mobs in the farm）
  4. 【形容詞】（例：unprecedented weather event）これまでにない規模・程度の

⛏️ マインクラフト例文

⛏We built an unprecedented castle using only netherite blocks.

私たちはネザライトブロックだけを使ってかつてない城を建築しました。

/wi bɪlt ən ʌnˈprɛsədəntɪd ˈkæsəl ˈjuːzɪŋ ˈoʊnli ˈnɛðəraɪt blɑks/
  • built + an: tが未開放で鼻音/n/に先立つ [bɪl̚ən] ビルアン
  • unprecedented + castle: dが子音/k/に先立つため未開放 [ʌnˈprɛsədən̚dɪd ˈkæsəl]
