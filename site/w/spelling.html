spelling

名詞・動詞/ˈspɛlɪŋ/CEFR A2英検3級 #726
  1. 【名詞】単語や文字を正確に綴ること、つづり方（…の spelling で「～のつづり」）
  2. 【名詞】単語や語句の正確な字句表記（how the word is spelled）
  3. 【動詞】文字を並べて単語を作る、綴る（...spell...out で「～を綴って説明する」）
  4. 【名詞】綴り字、正書法の技能・能力
  5. 【動詞】（過去形 spelled/spelt）単語を一文字ずつ言う、綴る

⛏️ マインクラフト例文

⛏The sign's spelling of 'MINECRAFT' was perfect.

そのサインの'MINECRAFT'のつづり方は完璧だった。

/ðə ˈsaɪnz ˈspɛlɪŋ əv maɪnˈkræft wəz ˈpɜrfɪkt/
  • sign's の語末 /z/ が spelling の /sp/ に子音+子音で続く（連結なし）
  • spelling の語末 /ŋ/ が of の /ə/ に鼻音+母音で連結 [ˈspɛlɪŋ əv] スペリング オブ
  • of は弱形 /əv/ で 'MINECRAFT' の /m/ に子音+子音で続く（連結なし）
ザ サインズ スペリング オブ マインクラフト ワズ パーフィクト

⛏I can spell this player's name quickly.

このプレイヤーの名前を素早く綴ることができる。

/aɪ kən ˈspɛl ðɪs ˈpleɪərz ˌneɪm ˈkwɪkli/
  • can は助動詞で弱形 /kən/ に弱化し spell の /sp/ に子音+子音で続く [kən ˈspɛl] カン スペル
  • spell の語末 /l/ が this の /ð/ に子音+子音で続く（連結なし）
  • this の語末 /s/ が player's の /pl/ に子音+子音で続く（連結なし）
  • player's の語末 /z/ が name の /n/ に子音+子音で続く（連結なし）
アイ カン スペル ディス プレイヤーズ ネイム クウィックリー

⛏Spelling commands correctly is essential for redstone.

コマンドを正確に綴ることはレッドストーンに不可欠だ。

/ˈspɛlɪŋ kəˈmændz ˈkɛrəktli ɪz ɪˈsɛnʃəl fɔr ˈrɛdˌstoʊn/
  • spelling の語末 /ŋ/ が commands の /k/ に鼻音+子音で続く（連結なし）
  • commands の語末 /z/ が correctly の /k/ に子音+子音で続く（連結なし）
  • is の語末 /z/ が essential の /ɪ/ に子音+母音で連結、is は弱形 /əz/ [ɪz ɪˈsɛnʃəl] イズ イセンシャル
  • for は弱形 /fər/ で redstone の /r/ に子音+子音で続く（連結なし）
スペリング コマンドズ ケレクトリー イズ イセンシャル フォー レッドストーン

💬 よく使う熟語（マイクラ例文）

spell out（何かを）綴って説明する、詳しく説明する、明確に述べる

⛏Let me spell out how to build this redstone contraption.

このレッドストーン装置の作り方を詳しく説明させてくれ。

/lɛt mi ˈspɛl aʊt haʊ tə ˈbɪld ðɪs ˈrɛdˌstoʊn kənˈtræpʃən/
  • me は弱形 /mi/ で spell の /sp/ に子音+子音で続く [mi ˈspɛl] ミー スペル
  • spell の語末 /l/ が out の /aʊ/ に連結 [ˈspɛl aʊt] スペラウト
  • out の語末 /t/ が how の /h/ に未開放で続く [aʊt̚ haʊ] アウッ ハウ
  • to は弱形 /tə/ で build の /b/ に子音+子音で続く [tə ˈbɪld] タ ビルド

マインクラフトのモブの名前を使ってスペリング・ビーをすることができる。

/wi kəd həv ə ˈspɛlɪŋ bi ˈjuːzɪŋ ˈmaɪnˌkræft moʊb neɪmz/

  • a は弱形 /ə/ で spelling の /sp/ に子音+子音で続く（連結なし）
  • bee の語末 /i/ が using の /j/ に母音+子音で続く（連結なし）
  • Minecraft の語末 /t/ が mob の /m/ に未開放で続く [krɑft̚ moʊb] クラフッ モウブ
