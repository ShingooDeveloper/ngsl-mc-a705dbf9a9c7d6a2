bug

名詞・動詞/bʌg/CEFR A2ターゲット1900 #1270
  1. 【名詞】昆虫や小さな生き物（silverfish など）
  2. 【名詞】プログラムやゲームの不具合（a bug in the code など）
  3. 【動詞】～を悩ませたり、～にしつこく言いかけたりする
