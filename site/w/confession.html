confession

名詞/kənˈfɛʃən/CEFR B2英検2級 #2175英検準1級 #316
  1. 【名詞】罪や過ちを認めて告白すること。白状（…admission or disclosure of guilt）。
  2. 【名詞】（法律）犯罪などの罪状を認める陳述。自白（…statement admitting to a crime）。
  3. 【名詞】秘密や私的な事柄を打ち明けること。暴露（…disclosure of something private）。

⛏️ マインクラフト例文

⛏My confession was that I destroyed the village with TNT by accident.

私の告白は、TNTで村を偶然破壊してしまったということだった。

[maɪ kənˈfɛʃən wəz ðæt aɪ dɪˈstrɔɪd ðə ˈvɪlɪdʒ wɪð ˈtiːˈɛnˈtiː baɪ ˈæksɪdənt]
  • that I → /t/ と母音 /aɪ/ が続く。that /ðæt/ の語末 /t/ が母音で始まる I に続くため、フラップT化して [ðæɾ aɪ] → 「ザッラ」。
  • destroyed the → /d/ と /ə/ が続く。destroyed /dɪˈstrɔɪd/ の語末 /d/ が the の母音 /ə/ に連結 [dɪˈstrɔɪdə]、さらに the の /ð/ が加わって [dɪˈstrɔɪd ðə] → 「デストロイド ザ」。
  • with TNT → th と t が続く。子音同士なので [wɪθ ˈtiːɛnˈtiː] で連結なし。with の th は強形 [θ]。

⛏The player made a full confession about wasting diamonds on tools.

そのプレイヤーは、ツールにダイヤモンドを浪費したことを完全に白状した。

[ðə ˈpleɪər ˈmeɪd ə ˌfʊl kənˈfɛʃən əˈbaʊt ˈweɪstɪŋ ˈdaɪəmɑndz ɑn ˈtulz]
  • The player → /ə/ と /p/ が続く。the /ðə/ が弱形で、player /ˈpleɪər/ に続くが、p は子音なので [ðə ˈpleɪər] → 「ザ プレイアー」。
  • confession about → /ən/ と /ə/ が続く。confession の語末 /n/ が about の母音 /ə/ に連結 [ʃən əˈbaʊt] → 「シュン アバウト」。連結により滑らか。
  • on tools → on が弱形 /ɑn/ で、tools /tulz/ の /t/ に続く。子音+子音なので連結なし。on は自然と弱化して [ɑn ˈtulz] → 「オン トゥールズ」。

⛏After losing everything, his confession revealed how hardcore mode works.

すべてを失った後、彼の告白はハードコアモードの仕組みを明かした。

[ˈæftər ˈluzɪŋ ˈɛvrɪθɪŋ hɪz kənˈfɛʃən rɪˈvild ˌhaʊ ˈhɑrdˌkɔr ˈmoʊd ˈwɝks]
  • losing everything → /ŋ/ と /ɛ/ が続く。losing /ˈluzɪŋ/ の語末 /ŋ/ と everything /ˈɛvrɪθɪŋ/ の /ɛ/ は、鼻音+母音の境界。ここでは /ŋ/ は鼻音なので連結を起こさず [ˈluzɪŋ ˈɛvrɪθɪŋ] → 「ルージング エブリスィング」。
  • his confession → /z/ と /k/ が続く。his /hɪz/ の語末 /z/ と confession /kənˈfɛʃən/ の /k/ は子音同士なので連結なし。[hɪz kənˈfɛʃən] → 「ヒズ コンフェッション」。
  • revealed how → /d/ と /h/ が続く。revealed /rɪˈvild/ の語末 /d/ と how /haʊ/ の /h/ は子音同士。h は時に弱化するが、基本的に [rɪˈvild haʊ] → 「リヴィールド ハウ」。

💬 よく使う熟語（マイクラ例文）

make a confession…を告白する。白状する。秘密を打ち明ける。

⛏The builder had to make a confession about using creative mode in survival.

そのビルダーはサバイバルでクリエイティブモードを使ったことを告白しなければならなかった。

[ðə ˈbɪldər həd tə ˈmeɪk ə kənˈfɛʃən əˈbaʊt ˈjuzɪŋ kriˈeɪtɪv ˈmoʊd ɪn sərˈvaɪvəl]
  • had to → d と t が続く。had /hæd/ の語末 /d/ が to /tu/ の /t/ に対して未開放で、1つの音のように聞こえる。to は弱形 /tə/。[hæd̚ tə] → 「ハッ タ」。
  • make a → k と ə が続く。make /meɪk/ の語末 /k/ が a /ə/ の母音に連結 [ˈmeɪkə] → 「メイカ」。
  • confession about → /ən/ と /ə/ が続く。confession の語末 /n/ が about の母音に連結 [ʃən əˈbaʊt] → 「シュン アバウト」。
