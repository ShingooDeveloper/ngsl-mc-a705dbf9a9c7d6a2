lust

動詞・名詞/lʌst/CEFR B2英検準1級 #2241
  1. 【動詞】激しく欲しがる；渇望する（…for）（物・成就などを強く望む）
  2. 【動詞】性的欲望を持つ（…after）
  3. 【名詞】激しい欲望；渇望（…for）（力・支配・成功への強い欲求）

⛏️ マインクラフト例文

⛏I lust for those enchanted diamonds in the deep cave.

深い洞窟にあるエンチャント付きダイヤモンドを激しく欲しい。

/aɪ ˈlʌst fɔɹ ðoʊz ɪnˈtʃæntəd ˈdaɪmənds ɪn ðə dip keɪv/
  • those enchanted：those /ðoʊz/ の語末の /z/ が enchanted /ɪnˈtʃæn/ の /ɪ/ に連結 [z ɪn]→「ザーズ イン」
アイ ラスト フォー ザーズ インチャンティド ダイモンズ イン ザ ディープ ケイヴ

⛏The server admin lusted after complete control.

そのサーバー管理者は完全な支配を激しく望んだ。

/ðə ˈsɜɹvɚ ˈædmɪn ˈlʌstɪd ˈæftɚ kəmˈplit kənˈtɹoʊl/
  • lusted after：lusted /ˈlʌstɪd/ の語末の /d/ が after /ˈæftɚ/ の /æ/ に連結 [d æ]→「ダ アフター」
ザ サーバー アドミン ラスティド アフター コンプリート コントロール

⛏Players lust for rare loot they might never obtain.

プレイヤーたちは決して手に入らないかもしれないレアアイテムを激しく望んでいる。

/ˈpleɪɚz ˈlʌst fɔɹ rɛr lut ðeɪ maɪt ˈnɛvɚ əbˈteɪn/
  • lust for：lust /ˈlʌst/ の t が for /fɚ/（弱形）に先行、未開放 [ˈlʌs̚ fɚ]→「ラス フォー」
  • might never：might /maɪt/ の t が never /ˈnɛvɚ/ の n に未開放 [maɪt̚ ˈnɛ]→「マイッネヴァー」
プレイアーズ ラス フォー レア ルート ザイ マイッネヴァー アブテイン
