token

名詞/ˈtoʊkən/CEFR B1英検準1級 #281
  1. 【名詞】何かの代わり、記号、しるし（…token of appreciation 感謝の印…）
  2. 【名詞】証明書、認証用の符号（…access token アクセストークン…）
  3. 【名詞】ゲーム・報酬などで使う代用品、ポイント（…game token ゲーム用トークン…）

⛏️ マインクラフト例文

⛏I got a special token when I defeated the Ender Dragon.

Ender Dragon を倒したとき、特別なトークンをもらいました。

/aɪ ɡɑtə ˈspeʃəl ˈtoʊkən wɛn aɪ dɪˈfiːɾɪd ðə ˈɛndɚ ˈdreɪɡən/

  • defeated the で語末 /d/ が the の母音に連結、the は弱形 /ðə/
