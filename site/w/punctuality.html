punctuality

名詞/ˌpʌŋkˈtʃuːæləti/CEFR B1英検準1級 #1540
  1. 【名詞】時間に正確であること・守ること（the quality or habit of being on time）
  2. 【名詞】約束の時間や期限に遅れず行動する習慣（the practice of arriving or doing things at the expected time）
  3. 【名詞】信頼性・きちんとした態度（reliability and attention to detail regarding timing）

⛏️ マインクラフト例文

⛏Punctuality is important when meeting teammates for a raid.

レイドで仲間と会う時は、時間厳守が大切だ。

/ˌpʌŋkˈtʃuːæləti ɪz ɪmˈpɔrtənt wɛn ˈmiːtɪŋ ˈtiːmmeɪts fɔr ə ˈreɪd/
  • important when → /t̚ wɛn/ → important の語末 /t/ が未開放（インポーラント ウェン）
  • teammates for → /ts fɔr/ → teammates の語末 /ts/ が for に続く（ティームメイツ フォー）
  • for a → /ər ə/ → for の語末 /r/ が a の /ə/ に連結（フォーラ）
パンクチュアリティ イズ インポーラント ウェン ミーリング ティームメイツ フォーラ レイド

⛏The server admin values punctuality and kicks players who arrive late.

サーバー管理者は時間厳守を大切にしていて、遅刻者をキックする。

/ðə ˈsɜrvər ˈædmɪn ˈvæljuz pʌŋkˈtʃuːæləti ənd ˈkɪks ˈpleɪərz huː ərˈaɪv leɪt/
  • The server → /ðə ˈsɜr/ → The は機能語で弱形 /ðə/；server の語末 /r/ が admin の /ə/ に連結（ザ サーバー）
  • and kicks → /ən ˈkɪks/ → and は機能語で弱形 /ənd/ または /ən/（アンド キックス）
ザ サーバー アドミン ヴァリューズ パンクチュアリティ アンド キックス プレイヤーズ フー アライヴ レイト

⛏Without punctuality, coordinated building projects fall apart.

時間を守らなければ、協力して建設するプロジェクトは上手くいかない。

/wɪˈðaʊt pʌŋkˈtʃuːæləti ˌkoʊˈɔrdəneɪtɪd ˈbɪldɪŋ ˈprɑdʒɛkts fɔl əˈpɑrt/
  • Without punctuality → /t̚ pʌŋ/ → without の語末 /t/ が punctuality の /p/ に先立つが未開放（ウィザウト パンクチュアリティ）
  • coordinated building → /d ˈbɪl/ → coordinated の語末 /d/ が building の /b/ に続く（コオーディネイティド ビルディング）
  • projects fall → /ts fɔl/ → projects の語末 /ts/ が fall に続く（プロジェクツ フォル）
ウィザウト パンクチュアリティ コオーディネイリッド ビルディング プロジェクツ フォル アパート
