react

動詞・名詞/ri'ækt/CEFR B1頻度#2374
  1. 【動詞】（刺激や状況に）反応する、対応する（respond to）
  2. 【動詞】反発する、反論する（protest, disagree）
  3. 【名詞】反応、応答（response）

⛏️ マインクラフト例文

⛏I react quickly when a mob appears.

モブが現れたとき、私は素早く反応します。

/aɪ riˈækt ˈkwɪkli wɛn ə mɑb əˈpɪrz/
  • a は冠詞の弱形 /ə/ → ア
  • mob appears → mob の語末子音 /b/ が appears の /ə/ に連結 [mɑbəˈpɪrz] マバピアーズ
アイ リアクト クイックリー ウェン ア マバピアーズ

⛏The redstone reacted to my lever pull.

レッドストーンは私のレバー操作に反応しました。

/ðə ˈrɛdˌstoʊn riˈæktəd tə maɪ ˈliːvɚ pʊl/
  • the は冠詞の弱形 /ðə/ → ザ
  • to は機能語の弱形 /tə/ → タ
ザ レッドストーン リアクテッド タ マイ リーバー プル

⛏We should react fast to any danger.

どんな危険にも素早く反応するべきです。

  • to は機能語の弱形 /tə/ → タ
ウィ シュッド リアクト ファスト タ エニー デインジャー
