replaceable

形容詞/rɪˈpleɪsəbəl/CEFR B2英検準1級
  1. 【形容詞】取り替えることができる。交換可能な（…replaceable battery = 交換可能なバッテリー）
  2. 【形容詞】代わりのものがある。失っても大事でない（…replaceable parts = 交換可能な部品）
  3. 【形容詞】（Minecraft用語）置き換え可能な；ほかのブロックで置き換えられるブロック（water・tall grass など）

⛏️ マインクラフト例文

⛏Water is a replaceable block you can walk through.

水は置き換え可能なブロックで、歩いて通り抜けられます。

/ˈwɔɾər ɪz ə rɪˈpleɪsəbəl ˈblɑk ˈjuː kæn ˈwɔk ˈθɹuː/
  • water の t がフラップ化し母音に連結 [ˈwɔɾə] ウォーラー
  • is が弱形 [ɪz]、a の /ə/ に連結 [ɪzə]
  • walk と through の語境界では特別な音変化なし
ウォーラー イザ リプレイサブル ブロック ユー キャン ウォーク スルー

⛏Tall grass is replaceable so mobs can pass through easily.

背の高い草は置き換え可能なので、モブが簡単に通り抜けられます。

/ˈtɔl ˈɡɹæs ɪz rɪˈpleɪsəbəl ˈsoʊ ˈmoʊbz kæn ˈpæs ˈθɹuː ˈiːzɪli/
  • grass の s が is の母音 /ɪ/ に連結 [ɡɹæz ɪz] グラスイズ
  • pass の s が through の /θ/ に先行（子音クラスタ）[pæs θɹuː] パススルー
  • easily の /z/ が /i/ に連結 [ˈiːzɪli] イージリ
トール グラスイズ リプレイサブル ソウ モウブズ キャン パススルー イージリ

⛏These replaceable blocks don't need any tools to break.

これらの置き換え可能なブロックは道具がなくても壊せます。

/ðiːz rɪˈpleɪsəbəl ˈblɑks ˈdoʊnt ˈniːd ˈɛni ˈtulz tə ˈbɹeɪk/
  • These の z が replaceable の r に連結 [ðiːz rɪ...] ディーズ リ
  • don't の t が未開放で need に先行 [doʊnt̚ niːd] ドウント ニード
  • to が弱形 /tə/、break の /br/ に連結 [tə ˈbɹeɪk] タ ブレイク
