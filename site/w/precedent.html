precedent

名詞/ˈprɛsɪdənt/CEFR B2英検準1級 #2478
  1. 【名詞】先例・前例（これまでの行為や決定が後の基準になる実例）
  2. 【名詞】慣行・慣例（繰り返される行為ややり方）
  3. 【名詞】判例（法的決定の基準となる過去の判決）

⛏️ マインクラフト例文

⛏We need a clear precedent for building in this village.

この村での建築には明確な先例が必要です。

/wi ˈniːd ə ˈklɪr ˈprɛsɪdənt fɔr ˈbɪldɪŋ ɪn ðɪs ˈvɪlɪdʒ/
  • need a の /d/ が /ə/ に連結 [ˈniːd ə] ニーダ
  • building in の /ŋ/ が /ɪ/ に連結 [ˈbɪldɪŋ ɪn] ビルディング イン
  • precedent は /t/ 未開放、for /f/ は連結なし [ˈprɛsɪdənt̚ fɔr]
  • in は機能語のため弱形の傾向あり
  • this は /ðɪs/
ウィ ニーダ クリア プレセデント フォー ビルディング イン ディス ヴィレッジ

  • to everyone の /ə/ が /ɛ/ に連結 [tə ˈɛvɹiwʌn] タ エブリワン
  • everyone on の /n/ が /ɑ/ に連結 [ˈɛvɹiwʌn ɑn] エブリワン オン
  • on は弱形の傾向あり

⛏We set a precedent for how redstone circuits should be organized.

レッドストーン回路をどのように整理するかについての先例を作りました。

/wi ˈsɛt ə ˈprɛsɪdənt fɔr ˈhaʊ ˈɹɛdˌstoʊn ˈsɝkɪts ʃʊd bi ˈɔrɡənɪzd/
  • set a の /t/ が /ə/ に連結 [ˈsɛt ə] セッタ
  • a precedent の /ə/ が /p/ に連結せず、precedent は /t/ 未開放 [ə ˈprɛsɪdənt̚]
