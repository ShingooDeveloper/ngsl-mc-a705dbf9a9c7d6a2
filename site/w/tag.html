tag

名詞・動詞/tæɡ/CEFR A2ターゲット1400 #1265
  1. 【名詞】（ゲームの）鬼ごっこ（a playground game where one player chases others to catch them）
  2. 【名詞】（物に付ける）タグ、ラベル、札（a label or marker attached to identify something）
  3. 【名詞】（システムの）識別マーク（a label used to categorize or mark entities in a system）
  4. 【動詞】～にタグを付ける、ラベルを貼る（to attach a label to something）
  5. 【動詞】（ゲームで）～を捕まえる、鬼ごっこで～を鬼にする（to catch or mark someone in a game）
