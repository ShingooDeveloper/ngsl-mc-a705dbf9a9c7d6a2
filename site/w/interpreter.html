interpreter

名詞/ɪnˈtɝːprɪtər/CEFR B2英検準1級 #448
  1. 【名詞】言語の通訳者；特に口頭での翻訳を行う人（書き言葉の翻訳は translator）
  2. 【名詞】（物事・文化・ルールなどの）解釈者、意味や意図を説明・理解する人
  3. 【名詞】（プログラミング）インタプリタ；ソースコードを実行時に機械語に翻訳して実行するソフトウェア

⛏️ マインクラフト例文

⛏We need an interpreter for the Japanese server admin.

日本人サーバー管理者のために通訳者が必要だ。

/wi ˈniːd ən ˌɪnˈtɝːprɪtər fər ðə ˌdʒæpəˈniz ˈsɝːvɚ ˈædmɪn/
  • need の /d/ が an の /ə/ に連結 [niːdən]
  • an の /n/ が interpreter の /ɪ/ に連結（流れ込む）
  • interpreter の語中の t（-ritə- の /t/）がフラップ化し [ɾ] に変わり、ラ行発音になる
ウィー ニーダン インタープリラー ファーザ ジャパニーズ サーバー アドミン

⛏As an interpreter of redstone logic, she built amazing mechanisms.

レッドストーン論理の解釈者として、彼女は素晴らしい仕掛けを建築した。

/æz ən ˌɪnˈtɝːprɪtər əv ˈrɛdˌstoʊn ˈlɑdʒɪk ʃi bɪlt əˈmeɪzɪŋ ˈmɛkənˌɪzməz/
  • an の /n/ が interpreter の /ɪ/ に連結（鼻音のような流れ）
  • interpreter の /t/ がフラップ化し [ɾ]（ラ行）
  • of は弱形 /əv/ で interpreter の /ɚ/ と流れ込む
  • built の /t/ が amazing の /ə/ に連結してフラップ化 [bɪɾə]
アズ アン インタープリラー アヴ レッドストウン ロジック シー ビラ メイジング メカニズムズ

⛏The interpreter translated the Chinese player's instructions perfectly.

その通訳者は中国人プレイヤーの指示を完璧に翻訳した。

/ðə ˌɪnˈtɝːprɪtər trænzˈleɪtɪd ðə ˌtʃaɪˈniz ˈpleɪərz ɪnˈstrʌkʃənz ˈpɝːfɪktli/
  • The は弱形 /ðə/ で interpreter の /ɪ/ に流れ込む
  • interpreter の /t/ がフラップ化し [ɾɚ]（ラー）
  • translated の過去形の e 音が脱落気味で [trænzˈleɪɾɪd]
  • instructions の語末の /z/ が次の単語に詰まった未開放 [nz̚]
ザ インタープリラー トランズレイリド ザ チャイニーズ プレイヤーズ インストラクションズ パーフェクトリー

💬 よく使う熟語（マイクラ例文）

interpreter of + 名詞（分野・文化・ルール・デザインなどの）解釈者、専門的に説明・理解する人

⛏As an interpreter of ancient temple architecture, he showed us every detail of the design.

古い寺院建築の解釈者として、彼は設計のあらゆる細部を我々に示した。

/æz ən ˌɪnˈtɝːprɪtər əv ˈeɪnʃənt ˈtɛmpəl ˌɑɹkɪˈtɛktʃər hi ˈʃoʊd əs ˈɛvri dɪˈteɪl əv ðə dɪˈzaɪn/

  • interpreter の /t/ がフラップ化し [ɾɚ]
  • showed の /d/ が us の /ə/ に連結 [ʃoʊdəs]
