virtual

形容詞/ˈvɝːtʃuəl/CEFR B2ターゲット1400 #695
  1. 【形容詞】実質的な、本質的には；ほぼ（…virtually the same ほぼ同じ）
  2. 【形容詞】コンピュータやインターネットに存在する、仮想の（…existing in computer space or online）
  3. 【形容詞】デジタルで再現された、画面上の（…created digitally on screen or in software）
  4. 【形容詞】見かけ上の、見た目の；実質的な（…in essence; practically real）

⛏️ マインクラフト例文

⛏Minecraft is a virtual world where you can build anything you imagine.

マインクラフトは、あなたが想像したことなら何でも構築できる仮想世界です。

/ˈmaɪnˌkræft ɪz ə ˈvɝːtʃuəl wɝld wɛr ju kæn bɪld ˈɛniθɪŋ ju ɪˈmædʒɪn/
  • is の /z/ と a の /ə/ が連結し、[ɪzə] のように「イザ」と流れる。a は弱形 /ə/
  • build の語末 /d/ が anything の /ɛ/ に連結し、「ビルド」と「エニシング」が流れるように聞こえる
マインクラフト イザ ヴァーチュアル ワールド ウェア ユー キャン ビルド エニシング ユー イマジン

⛏In this virtual environment, you can experiment with redstone circuits safely.

この仮想環境では、レッドストーン回路を安全に試験できます。

/ɪn ðɪs ˈvɝːtʃuəl ɪnˈvaɪrənmənt ju kæn ɪkˈspɛrəmənt wɪð ˈrɛdˌstoun ˈsɝːkɪts ˈseɪfli/
  • the の弱形 /ðə/ が virtual の /v/ に続き、「ザ ヴァーチュアル」のように音が流れる
イン ディス ヴァーチュアル インヴァイロンメント ユー キャン イクスペリメント ウィズ レッドストーン サーキッツ セイフリー

⛏The virtual blocks don't obey real physics, so you can build floating structures.

/ðə ˈvɝːtʃuəl blɑks doʊnt oʊˈbeɪ ˈril ˈfɪzɪks soʊ ju kæn bɪld ˈfloʊtɪŋ ˈstrʌktʃɚz/
  • the の弱形 /ðə/ が virtual の /v/ に続き、「ザ ヴァーチュアル」のように音が流れる
