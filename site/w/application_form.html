application_form

名詞/ˌæplɪˈkeɪʃən ˈfɔrm/CEFR B1英検準1級 #2621
  1. 【名詞】申し込み用紙、申請書（職務、学校、許可等に応募するための正式な書類）
  2. 応募フォーム、出願様式（マインクラフトサーバーやギルドに参加するための公式なテンプレート）
  3. （形式的な）申し込み方法、応募手続き

⛏️ マインクラフト例文

⛏The application form for the guild requires your name and experience level.

ギルド用の申し込み用紙には、あなたの名前と経験レベルが必要です。

/ðə ˌæplɪˈkeɪʃən ˈfɔrm fɚ ðə ˈɡɪld rɪˈkwaɪrz jɔr ˈneɪm ən ɪkˈspɪriəns ˈlɛvəl/
  • 「The」は弱形 /ðə/（標準形 /ðiː/ が弱化）
  • 「for the」では、for の語末 /r/ が the の /ə/ に連結 [fɚ‿ðə]→「ファー ザ」
  • 「and」は弱形 /ən/、experience の /ɪ/ に連結 [ən‿ɪ]→「アン イ」
ザ アプリケイション フォーム ファー ザ ギルド リクワイアーズ ユア ネイム アン イクスピリエンス レベル

⛏Fill out this application form if you want to join our server.

当サーバーに参加したければ、この申し込み用紙に記入してください。

/fɪl ˈaʊt ðɪs ˌæplɪˈkeɪʃən ˈfɔrm ɪf ju ˈwɑnt tə dʒɔɪn ˈaʊr ˈsɜrvər/
  • 「out this」では、out の語末 /t̚/ が未開放で this の /ð/ に先行 [ˈaʊt̚ ðɪs]→「アウッ ディス」
  • 「this application」では、this の語末 /s/ が application の /æ/ に連結 [ðɪs‿ˌæ]→「ディス アプリケイション」
  • 「to」は弱形 /tə/（標準形 /tuː/ が弱化）join に先行 [tə‿dʒɔɪn]→「タ ジョイン」
フィル アウト ディス アプリケイション フォーム イフ ユー ウォント タ ジョイン アワー サーバー

⛏New players must submit their application forms before they can access the admin area.

新しいプレイヤーは、管理者エリアにアクセスする前に申し込み用紙を提出する必要があります。

/ˈnu ˈpleɪərz ˈmʌst səbˈmɪt ðɛr ˌæplɪˈkeɪʃən ˈfɔrmz bɪˈfɔr ðeɪ ˈkən ˈæksɛs ðə ˈædmɪn ˈeriə/
  • 「must submit」では、must の語末 /t̚/ が未開放で submit の /s/ に先行 [ˈmʌst̚ səb]→「マッ サブミット」
  • 「their application」では、their の語末 /r/ が application の /æ/ に連結 [ðɛr‿ˌæ]→「デア アプリケイション」
  • 「can」は弱形 /kən/（標準形 /kæn/ が弱化）、access の /æ/ に連結 [ˈkən‿ˈæk]→「カン アクセス」
