inventory

名詞/ˈɪnvən.tɔri/CEFR B1英検準1級 #2372
  1. 【名詞】(ゲーム内で)プレイヤーが携帯・保有するアイテムやリソースの保管場所、またはそのシステム
  2. 【名詞】商品・物品などの在庫、または現有する物品の数量・目録
  3. 【名詞】ある時点で保有・収蔵している物品・資源の総体

⛏️ マインクラフト例文

⛏My inventory is full, so I need to drop some diamonds before I can mine more ore.

インベントリがいっぱいなので、もっと鉱石を採掘する前にダイヤモンドをいくつか落とす必要があります。

/maɪ ˈɪnvəntɔri ɪz fʊl soʊ aɪ niːd tə drɑp səm ˈdaɪmændz bɪˈfɔr aɪ kæn maɪn mɔr ɔr/
  • need to → need の /d/ が to の弱形 /ə/ に連結 [ˈniːd ə]→「ニーダ」
  • before I → before の /r/ が I の /aɪ/ に連結 [bɪˈfɔr aɪ]→「ビフォー アイ」
  • more ore → more の /r/ が ore の /ɔ/ に連結 [mɔr ɔr]→「モー オー」
マイ インベントリ イズ フル ソー アイ ニーダ ドラップ サム ダイマンズ ビフォー アイ キャン マイン モー オー

⛏I checked my inventory and found I had enough diamonds to craft a new pickaxe.

インベントリをチェックして、新しいつるはしをクラフトするのに十分なダイヤモンドがあることを確認しました。

/aɪ tʃɛkt maɪ ˈɪnvəntɔri ænd faʊnd aɪ hæd ɪˈnʌf ˈdaɪmændz tə ˈkræft ə nu ˈpɪkæks/
  • found I → found の /d/ が I の /aɪ/ に連結 [ˈfaʊnd aɪ]→「ファウンド アイ」
  • had enough → had の /d/ が enough の /ɪ/ に連結 [hæd ɪˈnʌf]→「ハッド イナフ」
  • craft a → craft の /t/ が a の弱形 /ə/ に連結 [kræft ə]→「クラフト ア」
アイ チェクト マイ インベントリ アンド ファウンド アイ ハッド イナフ ダイマンズ タ クラフト ア ニュー ピックアックス

⛏Building a large castle quickly filled my inventory with blocks and ore.

大きな城を建築するとすぐにインベントリがブロックと鉱石でいっぱいになってしまった。

/ˈbɪldɪŋ ə ˈlɑrdʒ ˈkæsəl ˈkwɪkli fɪld maɪ ˈɪnvəntɔri wɪð blɑks ænd ɔr/
  • Building a → building の /ŋ/ が a の弱形 /ə/ に連結 [ˈbɪldɪŋ ə]→「ビルディング ア」
  • blocks and → blocks の /s/ が and の /æ/ に連結 [blɑks ænd]→「ブロックス アンド」
  • and ore → and の /d/ が ore の /ɔ/ に連結 [ænd ɔr]→「アンド オー」
ビルディング ア ラージ キャッスル クウィクリー フィルド マイ インベントリ ウィズ ブロックス アンド オー

/ˈɔlweɪz tʃɛk jɔr ˈɪnvəntɔri fɔr ˈɛni ˈjuːsfəl ˈaɪtəmz ˈæftər ˈmaɪnɪŋ/
