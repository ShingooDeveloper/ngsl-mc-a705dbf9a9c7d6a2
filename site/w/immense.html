immense

形容詞/ɪˈmɛns/CEFR B1ターゲット1400 #1400ターゲット1900 #1582
  1. 【形容詞】非常に大きい、広大な（extremely large in size or extent）
  2. 莫大な、途方もない（very great in amount or degree）

⛏️ マインクラフト例文

⛏This immense cave system contains diamonds everywhere.

この途方もない洞窟システムはいたるところにダイヤモンドがあります。

/ðɪs ɪˈmɛns ˈkeɪv ˈsɪstəm kənˈteɪnz ˈdaɪmənz ˈɛvrɪwɛr/
  • This の /s/ が immense の /ɪ/ に連結
  • diamonds の /z/ が everywhere の /ɛ/ に連結
ディスイメンス ケイブ システム コンテインズ ダイマンズエヴリウェア

⛏The nether is an immense dimension with fire and lava.

ネザーは火と溶岩に満ちた途方もない次元です。

/ðə ˈnɛðər ɪz ən ɪˈmɛns dɪˈmɛnʃən wɪð ˈfaɪr ənd ˈlɑvə/
  • the は弱形 /ðə/
  • nether の /r/ が is の /ɪ/ に連結
  • an は弱形 /ən/ で、/n/ が immense の /ɪ/ に連結
  • fire の /r/ が and の /ə/ に連結、and は弱形 /ənd/

⛏We built an immense farming structure to grow crops.

私たちは作物を育てるために途方もない農業用建造物を建設しました。

/wi bɪlt ən ɪˈmɛns ˈfɑrmɪŋ ˈstrʌktʃər tə ɡroʊ krɑps/
  • built の /t/ が an の /ə/ に連結（フラップ化して /ɾ/）
  • farming の /ŋ/ は子音で、structure の /s/ に連結しない（子音+子音）
  • to は弱形 /tə/ で、/t/ が grow の /ɡ/ に接近しない（子音+子音）
