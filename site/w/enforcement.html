enforcement

名詞/ɪnˈfɔːrsmənt/CEFR B2英検準2級 #228
  1. 【名詞】法律や規則を強制的に従わせること；施行。規則の遵守を強制すること（enforcement of laws/rules）
  2. 【名詞】人や組織に無理やり何かをさせる行為；強制

⛏️ マインクラフト例文

⛏The server enforces strict building codes to prevent griefing.

そのサーバーは厳格な建築ルールを施行して、グリーフィングを防止している。

/ðə ˈsɜːrvər ɪnˈfɔːrsɪz strɪkt ˈbɪldɪŋ ˈkoʊdz tə prɪˈvɛnt ˈɡriːfɪŋ/
  • server enforces → 語末 /r/ が母音 /ɪ/ に連結 [ˈsɜːrvər ɪnˈfɔːrsɪz] サーヴァー・インフォースィズ
  • to prevent → to は機能語で弱形 /tə/ [tə prɪˈvɛnt] タ・プリベント
  • prevent griefing → prevent の語末 /n/ と /t/ は未開放 [prɪˈvɛn̚t̚ ˈɡriːfɪŋ] プリベント・グリーフィング
ザ・サーヴァー・インフォースィズ・ストリクト・ビルディング・コーズ・タ・プリベント・グリーフィング

⛏Without proper enforcement of rules, the world would be chaotic.

ルールの適切な施行がなければ、ワールドは混沌としただろう。

/wɪˈðaʊt ˈprɑpər ɪnˈfɔːrsmənt əv rulz ðə wɜːrld wəd bi keɪˈɑːtɪk/
  • proper enforcement → 語末 /r/ が母音 /ɪ/ に連結 [ˈprɑpər ɪnˈfɔːrsmənt] プロパー・インフォースメント
  • enforcement of → 語末子音 /t/ が母音 /ə/ に連結。of は弱形 /əv/ [ɪnˈfɔːrsmənt əv] インフォースメント・アヴ
  • the world → the は弱形 /ðə/ [ðə wɜːrld] ザ・ワールド
ウィザウト・プロパー・インフォースメント・アヴ・ルーズ・ザ・ワールド・ウッド・ビー・ケイアーティック

⛏We need to enforce the survival rules carefully.

私たちは生存モードのルールを慎重に施行する必要がある。

/wi niːɾə ɪnˈfɔːrs ðə sərˈvaɪvəl rulz ˈkɛrfəli/
  • need to → need の /d/ は母音に挟まれてフラップ化。to は弱形 /tə/ [niːɾə] ニーラ
  • to enforce → to は弱形 /tə/ で、次の /ɪ/ に連結 [tə ɪnˈfɔːrs] タ・インフォース
  • the survival → the は弱形 /ðə/ [ðə sərˈvaɪvəl] ザ・サーヴァイヴァル
ウィ・ニーラ・インフォース・ザ・サーヴァイヴァル・ルーズ・ケアフリー
