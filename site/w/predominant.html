predominant

形容詞/prɪˈdɑmɪnənt/CEFR B2英検準1級 #2767
  1. 【形容詞】最も目立つ、強大、または重要（…において最高の影響力または顕著な特徴を有する）
  2. 【形容詞】支配的な、主要な（…における主流または一般的な）
  3. 【形容詞】優勢の、数や力で勝る（…で数が多い、または力が強い）

⛏️ マインクラフト例文

⛏Diamonds are the predominant ore for powerful tools.

強力なツール用には、ダイヤモンドが支配的な鉱石である。

/ˈdaɪəmɑndz ɑr ðə prɪˈdɑmɪnənt ɔr fɚ ˈpaʊərfl ˈtulz/
  • are /r/ + the /ðə/ (弱形) → 分離 [ɑr ðə] → ア ザ
  • predominant /t/ + ore /ɔ/ に連結 [prɪˈdɑmɪnən‿ɔr] → プリダミナント オア
  • for /fɚ/ (弱形) + powerful /ˈpaʊ/ → 分離 → ファー パワフル
ダイアモンズ ア ザ プリダミナント オア ファー パワフル トゥールズ

⛏The predominant biome near spawn is grassland.

スポーン近くの支配的なバイオームは草地である。

/ðə prɪˈdɑmɪnənt baɪˈoʊm nɪr spaʊn ɪz ˈɡræslænd/
  • the /ðə/ (弱形) before consonant "predominant" → ザ
  • predominant /t/ + biome /b/ に未開放 [prɪˈdɑmɪnən̚ baɪˈoʊm] → プリダミナント バイオーム
  • near /r/ + spawn /s/ → 分離 → ニア スパウン
  • is /z/ + grassland /ɡ/ → 分離 → イズ グラスランド
ザ プリダミナント バイオーム ニア スパウン イズ グラスランド

⛏Stone bricks are predominant in ancient fortresses.

石レンガは古代要塞に支配的である。

/stoʊn brɪks ɑr prɪˈdɑmɪnənt ɪn ˈeɪnʃənt ˈfɔrtrəsɪz/
  • stone /n/ + bricks /b/ → 分離 → ストーン ブリックス
  • are /r/ + predominant /p/ → 分離 → ア プリダミナント
  • in /n/ + ancient /ˈeɪ/ (母音) に連結 [ɪn‿ˈeɪnʃənt] → イン エイシャント
  • ancient /t/ + fortresses /f/ に未開放 [ˈeɪnʃən̚ ˈfɔrtrəsɪz] → エイシャント フォートレシズ
ストーン ブリックス ア プリダミナント イン エイシャント フォートレシズ
