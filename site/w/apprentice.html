apprentice

名詞・動詞/əˈprɛntɪs/CEFR B1英検準1級 #1755
  1. 【名詞】修行中の職人；技術を習得している若年労働者。
  2. 【名詞】初心者；ある分野で経験が浅い人。
  3. 【動詞】修行する；~の下で技術を習得する、または~を修行させる。

⛏️ マインクラフト例文

⛏An apprentice learns a set of essential skills.

見習い職人は必要不可欠なスキルを習得します。

[ən əˈprɛntɪs ˈlɝnz ə ˈsɛɾəv ɪˈsɛnʃəl skɪlz]
  • an apprentice → n が母音に連結 [ən əˈprɛntɪs] エン アプレンティス
  • set of → t が両母音に挟まれてフラップ化 [ˈsɛɾəv] セラヴ。of は弱形 /əv/
エン アプレンティス ラーンズ ア セラヴ イセンシャル スキルズ

⛏He apprenticed to a master builder for three years.

彼は3年間、最高の建築家の下で修行しました。

[hi əˈprɛntɪst̚ə ə ˈmæstɚ ˈbɪldɚ fɚ θriː ˈjɝz]
  • apprenticed to → apprenticed の語末 /t/ が未開放で to の弱形 /tə/ に連接 [əˈprɛntɪst̚ə] アプレンティスタ
  • for three → for は弱形 /fɚ/
ヒ アプレンティスタ ア マスター ビルダー ファー スリー イアーズ

⛏The apprentice improved a lot of skills.

その見習い職人は多くのスキルを向上させました。

[ðə əˈprɛntɪs ɪmˈpruːvdə ˈlɑɾəv skɪlz]
  • improved a → d が母音に連結 [ɪmˈpruːvdə] イムプルーヴダ
  • lot of → t が両母音に挟まれてフラップ化 [ˈlɑɾəv] ラーラヴ。of は弱形 /əv/
ザ アプレンティス イムプルーヴダ ラーラヴ スキルズ
