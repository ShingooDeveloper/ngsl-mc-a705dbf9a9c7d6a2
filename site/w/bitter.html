bitter

形容詞/ˈbɪtər/CEFR B1ターゲット1200 #743ターゲット1400 #1297
  1. 【形容詞】苦い、不快な味がする（having a sharp, unpleasant taste）
  2. 【形容詞】辛い、つらい、悔しい（difficult or unpleasant to bear）
  3. 【形容詞】厳しい、激しい、激化した（marked by intensity or severity）

⛏️ マインクラフト例文

⛏This bitter potion tastes awful; I don't want to drink it.

このビター効果のポーション、ひどい味がする。飲みたくない。

/ðɪs ˈbɪtər ˈpoʊʃən ˈteɪsts ˈɔfəl aɪ ˈdoʊnt wɑnt tə ˈdrɪŋk ɪt/
  • bitter と potion の間で音声は自然に流れる
  • want to → to は機能語で弱形 /tə/
ディス ビッター ポウシャン テイスツ オーフル。アイ ドウント ウォント タ ドリング イット。

⛏We suffered a bitter defeat when the wither destroyed our base.

ウィザーが私たちのベースを破壊したとき、悔しい敗北を喫しました。

/wi ˈsʌfərd ə ˈbɪtər dɪˈfit wɛn ðə ˈwɪðər dɪˈstrɔɪd ˈaʊər ˈbeɪs/
  • suffered と a は自然に流れる。a は弱形 /ə/
  • bitter と defeat の間で /r/ と /d/ は明確に分かれる。defeat の /t/ は未開放

/ˈmaɪnɪŋ ɪn ˈbɪtər ˈkoʊld ˈbaɪoʊmz ˈlaɪk ˈaɪs ˈpleɪnz rɪˈkwaɪərz ˈhɛvi prəˈtɛkʃən/
  • bitter と cold の間で音声は自然に流れる。cold の /d/ は未開放
  • requires の /z/ と heavy の /h/ の間で音声は自然に流れる
