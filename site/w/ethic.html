ethic

名詞/ˈɛθɪk/CEFR B2ターゲット1900 #1054
  1. 【名詞】道徳原則、倫理（individual ethics など）
  2. 【名詞】職業上・組織内での行動基準、道徳規範（building ethics など）
  3. 【名詞】正しいと思われる行為の原則（work ethic など）

⛏️ マインクラフト例文

⛏Our server enforces a strong building ethic to protect player creations.

私たちのサーバーは、プレイヤーの建造物を保護するために強い建築倫理を実施しています。

[ˈaʊər ˈsɜrvər ɛnˈfɔrsəz ə ˈstrɔŋ ˈbɪldɪŋ ˈɛθɪk tə prəˈtɛkt ˈpleɪər kriˈeɪʃənz]
  • server の末尾 /r/ が enforces の /ɛ/ に連結 [ˈsɜrvər ɛn] → サーバー エンフォース
  • a は弱形 /ə/ に弱化し、strong の /s/ に連結 [əˈstrɔŋ] → ア ストロング
  • building の末尾 /ŋ/ が ethic の /ɛ/ に連結 [ˈbɪldɪŋ ˈɛθɪk] → ビルディング エシック
アワー サーバー エンフォースーズ ア ストロング ビルディング エシック タ プロテクト プレイアー クリエイションズ

⛏The mining ethics of our guild prevent harvesting abandoned structures too quickly.

私たちのギルドの採掘倫理は、廃棄された構造物を急いで採掘することを防いでいます。

[ðə ˈmaɪnɪŋ ˈɛθɪks əv ˈaʊər ɡɪld prɪˈvɛnt ˈhɑrvəstɪŋ əˈbændənd ˈstrʌktʃərz tu ˈkwɪkli]
  • The は弱形 /ðə/ で mining の /m/ に連結 [ðə ˈmaɪnɪŋ] → ザ マイニング
  • mining の末尾 /ŋ/ が ethics の /ɛ/ に連結 [ˈmaɪnɪŋ ˈɛθɪks] → マイニング エシックス
  • of は弱形 /əv/ で guild の /ɡ/ に連結 [əv ˈɡɪld] → アヴ ギルド
  • prevent の末尾 /t/ が未開放になり、harvesting に続く [prɪˈvɛnt̚ ˈhɑrvəstɪŋ] → プリベント ハーベスティング
ザ マイニング エシックス アヴ アワー ギルド プリベント ハーベスティング アバンダンド ストラクチャーズ トゥー クウィックリー

⛏Every great builder has an exceptional work ethic and patience.

すべての優れたビルダーは、優れた仕事倫理と忍耐力を持っています。

[ˈɛvri ɡreɪt ˈbɪldər hæz ən ɪkˈsɛpʃənəl ˈwɜrk ˈɛθɪk ənd ˈpeɪʃəns]
  • builder の末尾 /r/ が has の /h/ に連結 [ˈbɪldər hæz] → ビルダー ハズ
  • has は末尾 /z/ が an の /ə/ に連結・an は弱形 [hæz ən] → ハズ アン
  • exceptional の末尾 /l/ が work の /w/ に連結 [ɪkˈsɛpʃənəl ˈwɜrk] → エクセプショナル ワーク
エブリー グレイト ビルダー ハズ アン イクセプショナル ワーク エシック アン ペイシャンス

🔤 活用形・複数形

ethics複数形/ˈɛθɪks/

The ethics of fair gameplay prevent griefing on our server.

公正なゲームプレイの倫理は、私たちのサーバー上でグリーフィングを防いでいます。

[ðə ˈɛθɪks əv ˌfɛr ˈɡeɪmˌpleɪ prɪˈvɛnt ˈɡriːfɪŋ ɑn ˈaʊər ˈsɜrvər]
  • The の子音 /ð/ が ethics の /ɛ/ に連結（弱形で発音）[ðə ˈɛθɪks] → ザ エシックス
  • of は弱形 /əv/ で fair の /f/ に先行 [əv ˌfɛr] → アヴ フェア
  • prevent の末尾 /t/ が未開放で griefing の /g/ に先行 [prɪˈvɛnt̚ ˈɡriːfɪŋ] → プリベント グリーフィング
  • on の末尾 /n/ が our の /aʊ/ に連結 [ɑn ˈaʊər] → オン アワー
ザ エシックス アヴ フェア ゲイムプレイ プリベント グリーフィング オン アワー サーバー

Speedrunners follow different ethics than casual builders do.

スピードランナーはカジュアルビルダーとは異なる倫理に従っています。

[ˈspiːdˌrənərz ˈfɑloʊ ˈdɪfərənt ˈɛθɪks ðæn ˈkæʒuəl ˈbɪldərz də]
  • different の末尾 /t/ が ethics の /ɛ/ に連結 [ˈdɪfərənt ˈɛθɪks] → ディファレント エシックス
  • than は /ðæn/ で casual の /k/ に先行（子音+子音）[ðæn ˈkæʒuəl] → ザン キャジュアル
  • builders の末尾 /z/ が do の /d/ に先行（子音+子音）、do は弱形 /də/ で発音 [ˈbɪldərz də] → ビルダーズ ダ
スピードランナーズ フォロー ディファレント エシックス ザン キャジュアル ビルダーズ ダ

あの採掘者は素晴らしい仕事倫理を持っています。彼は数時間効率よく掘り続けます。

[ðæt ˈmaɪnər hæz ən ɪnˈkrɛdəbəl ˈwɜrk ˈɛθɪk hi ˈdɪɡz ɪˈfɪʃəntli fər ˈaʊərz]
  • That の末尾 /t/ が miner の /m/ に連結・未開放 [ðæt̚ ˈmaɪnər] → ザッ マイナー
  • miner の末尾 /r/ が has の /h/ に連結 [ˈmaɪnər hæz] → マイナー ハズ
  • incredible の末尾 /l/ が work の /w/ に連結 [ɪnˈkrɛdəbəl ˈwɜrk] → インクレディバル ワーク
  • efficiently の末尾 /i/ が for の /f/ に続く（弱形 /fər/）[ɪˈfɪʃəntli fər] → エフィシェントリー ファー
