display

動詞・名詞/dɪˈspleɪ/CEFR B1頻度#1106
  1. 【動詞】表示する、見えるようにする（インベントリやステータスなど）
  2. 【動詞】展示する、飾る（アイテムや装飾品を目立たせる）
  3. 【名詞】ディスプレイ、表示画面
  4. 【名詞】展示、表示されたもの

⛏️ マインクラフト例文

⛏The inventory displays all your items.

インベントリはすべてのアイテムを表示します。

[ðə ɪnˈvɛntəri dɪsˈpleɪz ɔl jɔr ˈɪtəmz]
  • displays の z が all の o に連結
  • your の r が items の i に連結
ザ インベンタリ ディスプレイゾール ヨアリタムズ

[aɪ dɪsˈpleɪd maɪ ˈfeɪvərɪt ˈdaɪmənd ˈsɔrd ɑn ðə ˈwɔl ɪn ən ˈɪtəm ˈfreɪm]
  • sword の d が on の a に連結
  • wall の l が in の i に連結
  • in の n が an の a に連結
