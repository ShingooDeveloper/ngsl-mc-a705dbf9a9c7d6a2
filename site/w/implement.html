implement

動詞・名詞/ɪmˈplɛmənt/CEFR B1頻度#1737
  1. 【動詞】計画や決定を実行に移す（put a plan into effect）
  2. 【動詞】システムや機能を導入・設置する（introduce or install a system）
  3. 【動詞】実装する、技術的に組み込む（set up or incorporate in a technical system）
  4. 【名詞】道具・器具（a tool or piece of equipment）

⛏️ マインクラフト例文

⛏We need to implement the defense system before mobs arrive at night.

夜間にモブが到着する前に防衛システムを実装する必要があります。
