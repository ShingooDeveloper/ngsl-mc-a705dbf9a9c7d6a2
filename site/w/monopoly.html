monopoly

名詞/ˌmɑnəˈpoʊli/CEFR B1ターゲット1900 #1757
  1. 【名詞】市場やサービスにおける一企業・個人による独占的支配、独占供給（...に対する独占）
  2. 【名詞】独占の状態、独占権（...に関する専有権）
  3. 【名詞】市場競争を制限する独占的行為
  4. 【名詞】ボードゲーム『モノポリー』

⛏️ マインクラフト例文

⛏The server owner has a monopoly on all diamond mining areas.

サーバーオーナーはすべてのダイヤモンド採掘エリアを独占している。

/ðə ˈsɝvər ˈoʊnər hæzə məˈnɑpəli ɑn ɔl ˈdaɪmɑnd ˈmaɪnɪŋ ˈɛriəz/
  • owner has → 語末 r [ɚ] が消え、s が /ə/ に連結 [ˈoʊnə hæzə] → 「オウナ ハザ」
  • has a → 語末 /z/ が /ə/ に連結 [hæzə] → 「ハザ」
  • on all → on の n が all の /ɔ/ に連結 [ɑn ɔl] → 「アン オル」
ザ サーヴァー オウナ ハザ マナポーリー アン オル ダイモンド マイニング エリアズ

⛏Some players claim that one faction has a monopoly on trade routes.

あるプレイヤーたちは、一つのグループが商人ルートを独占していると主張している。

/səm ˈpleɪərz kleɪm ðæt wən ˈfækʃən hæzə məˈnɑpəli ɑn treɪd ˈraʊts/
  • has a → /z/ が /ə/ に連結 [hæzə] → 「ハザ」
サム プレイヤーズ クレイム ザット ワン ファクション ハザ マナポーリー アン トレイド ラウツ

⛏We need to break the monopoly by finding alternative resource locations.

代替リソースの場所を見つけることで独占を打ち破る必要がある。

/wi nid tə breɪk ðə məˈnɑpəli baɪ ˈfaɪndɪŋ ˌɔltɝˈnætɪv ˈrɛsɔrs loʊˈkeɪʃənz/
  • to break → to が弱形 /tə/ に弱化し、b に連結 [tə breɪk] → 「タ ブレイク」
  • the monopoly → the の /ə/ が monopoly の /m/ に連結 [ðə məˈnɑpəli] → 「ザ マナポーリー」
ウィ ニード タ ブレイク ザ マナポーリー バイ ファインディング オルターナティヴ レソース ロウケイションズ

Multiple monopolies affect the entire server economy.

複数の独占がサーバーの経済全体に影響を与える。

/ˈmʌltɪpəl məˈnɑpəliz əˈfɛkt ðə ɪnˈtaɪr ˈsɝvər ɪˈkɑnəmi/
  • monopolies affect → 語末 /z/ が /ə/ に連結 [məˈnɑpəliz əˈfɛkt] → 「マナポーリーズ アフェクト」
マルティプル マナポーリーズ アフェクト ザ イナタイア サーヴァー イコノミー

Players accept these monopolies on valuable ores.

プレイヤーたちはこれらの貴重な鉱石の独占を受け入れている。

/ˈpleɪərz əkˈsɛpt ðiz məˈnɑpəliz ɑn ˈvæljuəbəl ˈɔrz/

💬 よく使う熟語（マイクラ例文）

have a monopoly on〜を独占している、〜に関する独占権を持つ

⛏The richest player has a monopoly on emerald trading.

最も裕福なプレイヤーはエメラルド取引を独占している。

/ðə ˈrɪtʃɪst ˈpleɪər hæzə məˈnɑpəli ɑn ˈɛmərəld ˈtreɪdɪŋ/
  • richest player → 語末 /t/ が /p/ の前で未開放 [ˈrɪtʃəs ˈpleɪər] → 「リッチェス プレイヤー」
  • has a → /z/ が /ə/ に連結 [hæzə] → 「ハザ」
  • on emerald → on の n が emerald の /ɛ/ に連結 [ɑn ˈɛmərəld] → 「アン エメラルド」
ザ リッチェス プレイヤー ハザ マナポーリー アン エメラルド トレイディング
break a monopoly独占を打ち破る、独占状態を終わらせる

⛏Skilled miners eventually break the monopoly by mining deeper.

熟練した鉱夫は、より深く掘ることで最終的に独占を打ち破る。

/ˈskɪld ˈmaɪnərz ɪˈvɛntʃuəli breɪk ðə məˈnɑpəli baɪ ˈmaɪnɪŋ ˈdipər/
  • miners eventually → 語末 /z/ が /ɪ/ に連結 [ˈmaɪnərz ɪˈvɛntʃuəli] → 「マイナーズ イヴェントゥアリー」
  • the monopoly → /ə/ が /m/ に連結 [ðə məˈnɑpəli] → 「ザ マナポーリー」
