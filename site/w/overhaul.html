overhaul

動詞・名詞/ˌoʊvərˈhɔl/CEFR B2英検準1級 #3141
  1. 【動詞】（機械やシステムを）徹底的に点検し修理する。複雑な装置を完全に調べて必要な修理を行う（to inspect thoroughly and repair something complicated）
  2. 【名詞】徹底的な検査・修理。大規模な改修や全面改良（a thorough inspection and repair）
  3. 【動詞】（制度や方針を）根本的に改善・改革する。組織やシステムを大きく変える（to make major changes to improve or reform something）

⛏️ マインクラフト例文

⛏We need to overhaul the redstone circuit.

我々はレッドストーン回路をオーバーホールする必要があります。

[wiː niːd̚ tə‿ˌoʊvərˈhɔl ðə ˈrɛdˌstoʊn ˈsɝːkɪt]
  • need to → 語末子音 /d/ が未開放で次の /t/ に先立つ [niːd̚ tə]→「ニード タ」
  • to overhaul → 弱形 /tə/ が母音 /oʊ/ に連結 [tə‿ˌoʊvərˈhɔl]→「タ オーバーホール」
ウィー ニード タ オーバーホール ザ レッドストーン サーキット

⛏The enchantment system overhaul changed how we get better tools.

エンチャントシステムの大規模改修は、より良い道具の入手方法を変えました。

[ðə ɪnˈtʃæntmənt ˈsɪstəm‿ˌoʊvərˈhɔl ˈtʃeɪndʒd haʊ wiː ɡɛt̚ ˈbɛɾər ˈtuːlz]
  • the enchantment → 弱形 /ðə/ が母音 /ɪ/ に連結 [ðə‿ɪnˈtʃæntmənt]→「ザ インチャントメント」
  • system overhaul → 語末子音 /m/ が母音 /oʊ/ に連結 [ˈsɪstəm‿ˌoʊvərˈhɔl]→「システム オーバーホール」
  • get better → /t/ が未開放で [ɡɛt̚]、better の /t/ がフラップ化 [ˈbɛɾər]→「ゲッ ベラー」
ザ インチャントメント システム オーバーホール チェインジド ハウ ウィー ゲッ ベラー トゥールズ

⛏After the server overhaul, all our farms work much better.

サーバーのオーバーホール後、私たちのすべての農場がはるかに良く機能しています。

[ˈæftər‿ðə ˈsɝːvər ˌoʊvərˈhɔl ɔl ˈaʊər fɑːrmz wɝːk̚ mʌtʃ ˈbɛɾər]
  • After the → 語末子音 /r/ が母音 /ə/ に連結 [ˈæftər‿ðə]→「アフター ザ」
  • work much → 語末子音 /k/ が未開放で子音 /m/ に先立つ [wɝːk̚ mʌtʃ]→「ワーク マッチ」
アフター ザ サーバー オーバーホール オール アワー ファームズ ワーク マッチ ベラー
