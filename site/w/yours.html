yours

代名詞/jɔːrz/CEFR A1ターゲット中学1800 #1127
  1. 【代名詞】…のもの、…に属する（所有を表す代名詞；…This is yours.（これはあなたのもの）など）
  2. 【代名詞】あなたの（の）（…your に対応する所有格代名詞；…Mine is bigger than yours.（私のはあなたのより大きい）など）
  3. 【代名詞】（手紙・敬礼の結びで）…敬具（…Sincerely yours, Warmly yours など；署名の前の常套句）

⛏️ マインクラフト例文

⛏These are yours.

これらはあなたのものです。

[ðiːz ɑr ˈjɔːrz]
  • These の語末 /z/ が are の語初母音に連結して [ðiːzɑr] となる。
  • are は強形 /ɑr/（弱形 /ər/ ではなく）。
  • yours は /ˈjɔːrz/ で文末。
ディーズアー ジョーズ

⛏My diamond sword is better than yours.

私のダイヤモンドの剣の方があなたのより良い。

[maɪ ˈdaɪmənd sɔːrd ɪz ˈbɛtər ðən ˈjɔːrz]
  • sword の語末 /d/ が is の語初母音に連結して [sɔːrdɪz] となる。
  • better の /t/ が母音挟みでフラップ化 [ˈbɛɾər] ベッラー。
  • than は /ðən/。yours は /ˈjɔːrz/。
マイ ダイマンド ソーディズ ベッラー ザン ジョーズ

⛏Is this yours?

これはあなたのものですか？

[ɪz ðɪs ˈjɔːrz]
  • is と this は子音同士（/z/ と /ð/）で連結なし。
  • this の末尾 /s/ と yours の /j/ でも子音同士で分離。
  • is は通常通り強形 /ɪz/ で発音される。
イズ ディス ジョーズ

💬 よく使う熟語（マイクラ例文）

yours truly敬具（手紙の結び）；実は私、このしたり顔のあたし（冗談めかして自分を指す）

⛏Need someone to find a stronghold? That would be yours truly!

ストロングホールドを見つける人が必要？それは実は私です！

[ˈjɔːrz ˈtruːli]
  • yours の語末 /z/ と truly /t/ は子音同士で連結なし。
  • truly は /ˈtruːli/ で通常通り発音。
