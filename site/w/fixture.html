fixture

名詞/ˈfɪkstʃɚ/CEFR B1英検準1級 #2631
  1. 【名詞】建物や壁に固定された設備・器具（…light fixtures, bathroom fixtures）
  2. 【名詞】定期的に行われるスポーツ試合や試合予定表（…team fixture, match fixture）
  3. 【名詞】動かないように固定・設置された機械や装置（…permanent fixture）

⛏️ マインクラフト例文

⛏I'll install light fixtures around the new spawn point.

新しいスポーンポイントの周りに照明器具を取り付けます。

[aɪl‿ɪnˈstɔl laɪt̚ ˈfɪkstʃɚz‿əˈraʊnd ðə‿ˈnu ˈspɔn pɔɪnt]
  • I'll /l/ が install /ɪ/ に連結 [l‿ɪ]
  • light /t/ が fixtures /f/ の前で未開放 [t̚]
  • fixtures /z/ が around /ə/ に連結 [z‿ə]
  • the /ə/ が new /n/ に連結 [ə‿n]
アイル‿インストール ライッ フィクスチャーズ‿アラウンド ザ‿ニュー スポーン ポイント
