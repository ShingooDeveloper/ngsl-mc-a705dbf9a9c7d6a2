diverge

動詞/daɪˈvɝdʒ/CEFR B2英検準1級 #2409
  1. 【動詞】分かれる、分岐する（道や通路が二つ以上に分かれる）
  2. 【動詞】異なる、相違する（意見や進め方などが異なる）
  3. 【動詞】逸脱する、外れる（予定の方向から外れる）

⛏️ マインクラフト例文

⛏The cave system diverges into three main branches—which way should we go?

洞窟システムは3つの主な枝に分岐しています—どちらに進むべきでしょう？

[ðə ˈkeɪv ˈsɪstəm dɪˈvɝdʒəz ˈɪntu θri meɪn ˈbrænʃəz wɪtʃ weɪ ʃʊd wi ˈɡoʊ]
  • cave system の m /m/ が d に... 子音+子音なので連結なし
  • diverges into の s /z/ が i /ɪ/ に連結 [dɪˈvɝdʒəz‿ɪntu]
  • three main の /θ/ が m に、which の /tʃ/ が w に... 子音+子音/子音+接近音なので連結なし
ザ ケイヴ システム ディヴァージズ イントゥ スリー メイン ブランチズ ウィッチ ウェイ シュッド ウィ ゴウ

[ˈaʊr ˈmaɪnɪŋ ˈstrætədʒiz dɪˈvɝdʒ ju prɪˈfɚ ˈdaɪməndz waɪl aɪ ˈfoʊkəs ɑn ˈaɪrn ˈoʊr]
