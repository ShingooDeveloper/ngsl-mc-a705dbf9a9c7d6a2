texture

名詞/ˈtɛkstʃər/CEFR B1ターゲット1900 #1874英検準1級 #1621
  1. 【名詞】（表面の質感・手触り）物の表面の性質や質感（…smooth texture, rough texture など）
  2. 【名詞】（見た目・外観）ブロックや物体の視覚的な特徴や見た目
  3. 【名詞】（マインクラフト）ゲームの見た目を決めるリソースファイル、またはそれを提供するリソースパック

⛏️ マインクラフト例文

⛏The stone texture looks great in this build.

この建築物で石のテクスチャが素晴らしく見えます。

[ðə ˈstoʊn ˈtɛkstʃər ˈlʊks ɡreɪt ɪn ðɪs bɪld]
  • "The" が子音の前にあるため弱形 /ðə/ で発音 [ðə ˈstoʊn] → 「ザストーン」
  • "great in" で "great" の語末 /t/ は後続の母音 /ɪ/ の直前で未開放となり [ɡreɪt̚ ɪn] → 「グレイッ イン」と聞こえる
ザ ストーン テクスチャー ルックス グレイッ イン ディス ビルド

⛏I'm using a new texture pack that makes water look more realistic.

水をより現実的に見せる新しいテクスチャパックを使っています。

[aɪm ˈjuːzɪŋ ə ˈnjuː ˈtɛkstʃər pæk ðæt meɪks ˈwɔɾər lʊk moʊɹ riːˈælɪstɪk]
  • "a new" において "a" が子音 /n/ の直前で弱形 /ə/ に弱化 [ə ˈnjuː] → 「アニュー」
  • "water" の /t/ が母音に囲まれているためフラップT化し /ɾ/ に変わる [ˈwɔɾər] → 「ウォーラー」
アイム ユージング ア ニュー テクスチャー パック ザット メイクス ウォーラー ルック モア リーアリスティック

⛏This wood texture doesn't match the rest of the house.

この木のテクスチャが家の残りの部分と合いません。

[ðɪs wʊd ˈtɛkstʃər ˈdʌzənt mætʃ ðə rɛst əv ðə haʊs]
  • "rest of" において "of" の弱形 /əv/ が先行する語末に続き [ˈrɛst əv] → 「レスト アヴ」
  • "of the" で弱形 "of" /əv/ の v と "the" の ð が連続 [əvðə] → 「アヴザ」と聞こえる
ディス ウッド テクスチャー ダズント マッチ ザ レスト アヴ ザ ハウス

🔤 活用形・複数形

textures複数形/ˈtɛkstʃɚz/

Different textures for each block type make the world feel more immersive.

各ブロックタイプの異なるテクスチャは、世界をより没入感のあるものにします。

/ˈdɪfərənt ˈtɛkstʃɚz fɔr itʃ blɑk taɪp meɪk ðə wɝld fil moʊr ɪmˈmɝsɪv/
  • textures for - textures の語末 /z/ が for の初頭 /f/ に... 子音+子音なので連結なし。for は弱形 /fɔr/ ファ
  • each block - each の語末 /tʃ/ が block の初頭 /b/ に... 子音+子音なので連結なし
  • feel more - feel の語末 /l/ が more の初頭 /m/ に... 子音+子音なので連結なし
ディファレント テクスチャーズ ファ イーチ ブラック タイプ メイク ザ ワールド フィール モア イマーシヴ

I loaded high-resolution textures to replace the default block appearances.

デフォルトのブロック外観を置き換えるために、高解像度のテクスチャをロードしました。

/aɪ ˈloʊdɪd ˌhaɪ ˌrɛzəˈluːʃən ˈtɛkstʃɚz tu rɪˈpleɪs ðə dɪˈfɔlt blɑk əˈpɪrənsəz/
  • to は機能語の弱形 /tu/ タ
  • the は弱形 /ðə/
  • block appearances - block の語末 /k/ が appearances の初頭 /ə/ に連結 [blɑk əˈpɪrənsəz]
アイ ローディド ハイ レゾリューション テクスチャーズ タ リプレイス ザ ディフォルト ブラック アピアランシズ
