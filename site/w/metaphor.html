metaphor

名詞/ˈmetəfɔr/CEFR B2ターゲット1900 #961
  1. 【名詞】隠喩。2つのものを直接的に比較する修辞技法（like や as を使わない）。
  2. 【名詞】象徴的な表現。ある事柄を別のことで象徴的に説明する言い方。
  3. 【名詞】比喩によるもの。文字通りの意味ではなく、抽象的な概念を具体的にたとえた表現。

⛏️ マインクラフト例文

⛏Diamond mining is a metaphor for persistent effort and dedication.

ダイヤモンド採掘は、粘り強い努力と献身の隠喩である。

/ˈdaɪmənd ˈmaɪnɪŋ ɪz ə ˈmetəfɔr fər pɚˈsɪstənt ˈɛfɚt ənd ˌdɛdɪˈkeɪʃən/
  • 「is a」の連結：語末子音 /z/ が母音 /ə/ に連結 [ɪzə]「イザ」
  • 「for persistent」の連結：for の語末 /r/ が persistent の母音 /ɚ/ に連結 [fɚ]「ファー」。persistent 内の /st/ 子音クラスタ後の /t/ が母音に挟まれてフラップ化 [pɚˈsɪsɾənt]「パーシスレント」
  • 「effort and」：effort の語末 /t/ が未開放 [ˈɛfɚt̚]「エフォット」。and は弱形 /ənd/ に弱化し [ən]「ン」
ダイマンド マイニング イズ ア メタファー ファー パーシスレント エフォート アン デディケイション

⛏The Nether is a metaphor for Hell - dangerous, dark, and hostile.

ネザーは地獄の隠喩である。危険で暗く、敵対的だ。

/ðə ˈnɛðər ɪz ə ˈmetəfɔr fər hɛl ˈdeɪndʒərəs dɑrk ənd ˈhɑstəl/
  • 「The Nether」の弱形：The は /ðə/ に弱化し [ðə ˈnɛðər]「ザ ネザー」
  • 「is a」の連結：/z/ が /ə/ に連結 [ɪzə]「イザ」。「for Hell」の連結：for の /r/ が Hell の /h/ へ続く [fɚ ˈhɛl]「ファー ヘル」
  • 「dark」の語末 /k/ は未開放 [dɑrk̚]「ダーク」。and は弱形 [ən]「ン」
ザ ネザー イズ ア メタファー ファー ヘル デンジャラス ダーク ン ハースタル

⛏Your base design is a metaphor that reveals your building style and creativity.

基地の設計は、君の建築スタイルと創造性を表す隠喩である。

/jɔr beɪs dɪˈzaɪn ɪz ə ˈmetəfɔr ðæt rɪˈvilz jɔr ˈbɪldɪŋ ˈstaɪl ənd kriˌeɪˈtɪvəti/
  • 「is a」の連結：語末子音 /z/ が母音 /ə/ に連結 [ɪzə]「イザ」
  • 「that reveals」の連結：that の語末 /t/ が未開放 [ðæt̚]「ザッ」。reveals の /l/ + /z/ は word-final 子音クラスタ
  • 「and creativity」：and は弱形 [ən]「ン」。creativity の /ɪ/ が /v/ に連結し /ɪv/ で [ɪvə]「イヴァ」

🔤 活用形・複数形

metaphors複数形/ˈmetəfɔrz/

Many metaphors in Minecraft help us think about the game differently.

マインクラフトの多くの隠喩は、ゲームについて別の方法で考えるのに役立つ。

/ˈmɛni ˈmetəfɔrz ɪn ˈmaɪnkræft hɛlp əs θɪŋk əˈbaʊt ðə ˈgeɪm ˈdɪfərəntli/
  • 「metaphors in」：metaphors の語末 /z/ が in の /ɪ/ に連結 [ˈmetəfɔrz ɪn]「メタファーズ イン」
  • 「Minecraft help」：Minecraft の語末 /t/ が未開放 [ˈmaɪnkræft̚]「マインクラフト」
  • 「think about」：think の語末 /k/ が about の最初の /ə/ に連結 [θɪŋkəˈbaʊt]「シング カ バウト」
メニー メタファーズ イン マインクラフト ヘルプ アス シング アバウト ザ ゲイム ディファラアントリー

Players in the community use metaphors to describe their building techniques.

コミュニティ内のプレイヤーたちは、彼らの建築スタイルを説明するために隠喩を使う。

/ˈpleɪərz ɪn ðə kəˈmjuːnɪti ˈjuːz ˈmetəfɔrz tə dɪˈskraɪb ðɛr ˈbɪldɪŋ tɛkˈniːks/
  • 「Players in」：Players の語末 /z/ が in の /ɪ/ に連結 [ˈpleɪərz ɪn]「プレイヤーズ イン」
  • 「in the」：in の語末 /n/ が the の /ð/ へ続く。the は弱形 /ðə/ に弱化 [ɪn ðə]「イン ザ」
  • 「metaphors to」：metaphors の語末 /z/ が to の /t/ へ続く。to は弱形 /tə/ に弱化 [ˈmetəfɔrz tə]「メタファーズ タ」

💬 よく使う熟語（マイクラ例文）

a dead metaphor陳腐化した隠喩。非常に一般的になり過ぎて、隠喩としての力を失った表現。

⛏Calling Bedrock 'unbreakable' is almost a dead metaphor in Minecraft - everyone already knows it.

マインクラフトで Bedrock を『壊せない』と呼ぶのはほぼ陳腐化した隠喩だ。誰もがそのことを知っている。

/ˈkɔlɪŋ ˈbɛdˌrɑk ənˈbreɪkəbəl ɪz ˈɔlmoʊst ə dɛd ˈmetəfɔr ɪn ˈmaɪnkræft ˈɛvriˌwən ɔlˈrɛdi noʊz ɪt/
  • 「is almost」の連結：is の /z/ が almost の /ɔ/ に連結 [ɪzə]「イザ」
  • 「dead」の語末 /d/ は未開放 [dɛd̚]「デッ」。「metaphor in」の連結：metaphor の /r/ が in の /ɪ/ に連結 [ɪn]「イン」
  • 「already knows」：already は /ɔlˈrɛdi/（2音節目にストレス）。knows の /z/ が it の /ɪ/ に連結 [noʊz ɪt]「ノーズ イット」
