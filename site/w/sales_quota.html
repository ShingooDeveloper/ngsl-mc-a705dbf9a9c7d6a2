sales_quota

名詞/ˈseɪlz ˈkwoʊtə/CEFR B1英検準1級 #2041
  1. 【名詞】達成すべき営業目標、売上ノルマ（…a target amount of sales that a person or group is expected to achieve）
  2. 【名詞】割り当てられた販売数量または取引額（…a fixed amount or number of items allocated for trading）
  3. 【名詞】商業取引で定められた最小購売単位、販売枠（…a minimum quantity assigned for sales in a commercial transaction）

⛏️ マインクラフト例文

⛏We set a sales quota for our server marketplace this week.

私たちはこの週、サーバーマーケットプレイスの販売目標を設定した。

  • set a："set" の語末子音 /t/ が "a" の初頭母音 /ə/ に連結 [ˈsɛtə] セタ
  • for our："for" は弱形 /fɚ/、"our" も弱形 /ɚ/ で短縮される [fɚ ɚ] ファー アワー
  • this week："this" の語末 /s/ と "week" の初頭 /w/ は異なる子音なので連結なし [ðɪs wik] ディス ウィク
