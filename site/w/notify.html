notify

動詞/noʊˈtɪfaɪ/CEFR B1英検準1級 #2104
  1. 【動詞】ある人に何かを知らせる、通知する（tell someone about something; inform）
  2. 【動詞】正式に報告する、申告する（report officially）
  3. 【動詞】警告する、注意を促す（alert; give notice）

⛏️ マインクラフト例文

⛏I need to notify the admin about the griefing incident

グリーフィング事件について管理者に通知する必要があります

/aɪ niːd‿tə noʊˈtɪfaɪ ðə ˈædmɪn əˈbaʊt ðə ˈɡriːfɪŋ ˈɪnsɪdənt/
  • need to → need の /d/ が to の弱形 /tə/ に連結 [niːd‿tə]
  • the admin → the は弱形 /ðə/
  • about the → about の /t̚/ は未開放で次の子音 /ð/ に先行 [əˈbaʊt̚ ðə]
アイ ニード タ ノウティファイ ザ アドミン アバウト ザ グリーフィング インシデント

⛏The system will notify you when your smelter is done

あなたのかまどが完成したとき、システムはあなたに通知します

/ðə ˈsɪstəm wɪl noʊˈtɪfaɪ juː wɛn jɔr ˈsmɛltər ɪz dʌn/
  • the system → the は弱形 /ðə/
  • will notify → will は弱形 /wɪl/
  • is done → is は弱形 /ɪz/
ザ システム ウィル ノウティファイ ユー ウェン ヨー スメルター イズ ダン

⛏We should have notified the server owner before building here

ここに建築する前にサーバーの所有者に通知すべきでした

/wiː ʃʊd‿əv noʊˈtɪfaɪd ðə ˈsɝːvər ˈoʊnər bɪˈfɔr ˈbɪldɪŋ hɪr/
  • should have → have は弱形 /əv/, should の /d/ が /ə/ に連結 [ʃʊd‿əv]
  • the server → the は弱形 /ðə/
ウィー シュド ハヴ ノウティファイド ザ サーバー オウナー ビフォー ビルディング ヒア

💬 よく使う熟語（マイクラ例文）

notify of～(を人に)通知する、知らせる

⛏Notify the admin of any lag issues

ラグの問題について管理者に通知してください

/noʊˈtɪfaɪ ðə ˈædmɪn əv‿ˈɛni læɡ ˈɪʃuːz/
  • the admin → the は弱形 /ðə/
  • of any → of は弱形 /əv/, /v/ が /ɛ/ に連結 [əv‿ˈɛni]
