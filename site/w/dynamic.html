dynamic

形容詞・名詞/daɪˈnæmɪk/CEFR B1ターゲット1400 #1192ターゲット1900 #1083
  1. 【形容詞】活発で常に変化する、動的な（ゲーム内のシステムやプレイが絶えず動いて変わるさま）
  2. 【形容詞】精力的で生き生きした、活発な（戦術やプレイスタイルが積極的で力強い）
  3. 【形容詞】物理的な力や運動に関連した、力学的な
  4. 【名詞】（通常複数形 dynamics）力学、動力学、動く力のパターン

⛏️ マインクラフト例文

⛏We need a dynamic redstone circuit to power all these machines.

すべてのマシンに電力を供給するために、動的なレッドストーン回路が必要です。

/wiː ˈniːd ə daɪˈnæmɪk ˈrɛdstoʊn ˈsɜrkɪt tə ˈpaʊər ɔl ðiːz məˈʃiːnz/
  • need /d/ + a /ə/ が連結し、/ˈniːdə/ となる
  • redstone の s と circuit の c は両方子音で連結せず [ˈrɛdstoʊn ˈsɜrkɪt]
  • circuit /t/ + to /t/ は両方子音で連結せず
  • machines /z/ で終わり、パッセージの終了

⛏Take a dynamic approach—adjust your strategy based on the mob behavior.

動的なアプローチを取ってください。モブの動きに合わせて戦術を調整してください。

/ˈteɪk ə daɪˈnæmɪk əˈproʊtʃ—əˈdʒʌst jɔr ˈstrætədʒi ˈbeɪst ɑn ðə moʊb bɪˈheɪvjər/
  • take /k/ + a /ə/ が連結して [ˈteɪkə]
  • dash で分離されているため、approach と adjust は連結しない
  • the /ə/ (弱形) で始まるモブへ
  • behavior の r で文が終わる

⛏The dynamic lighting system in caves makes exploration more exciting.

/ðə daɪˈnæmɪk ˈlaɪtɪŋ ˈsɪstəm ɪn keɪvz meɪks ɪkˌsploʊˈreɪʃən mɔr ɪkˈsaɪtɪŋ/
  • the /ə/ (弱形) + dynamic /d/ で自然な流れ、特別な連結音ではなく

/ə ˌmɔr daɪˈnæmɪk ˈrɛdˌstoʊn ˈsɝkɪt kæn kriˈeɪt ˈkɑmplɛks ɔˈtɑmətɪd məˈʃɪnəri ðæt rɪˈspɑndz tu ˈtʃeɪndʒɪŋ kənˈdɪʃənz/
