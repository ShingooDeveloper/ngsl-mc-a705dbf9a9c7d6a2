wonder

動詞・名詞/ˈwʌndər/CEFR B1頻度#664
  1. 【動詞】〜かなと思う、疑問に思う（～について思考する、～を知りたいと思う）
  2. 【動詞】不思議に思う、驚く（～に驚く、～が奇妙だと感じる）
  3. 【名詞】不思議なもの、奇跡（珍しく素晴らしいもの、見る価値のあるもの）

⛏️ マインクラフト例文

⛏I wonder if there's a cave below this area.

この地域の下に洞窟があるのかな。

/aɪ ˈwʌndərɪf ðɛɹzə keɪv bɪˈloʊ ðɪs ˈɛɹiə/
  • wonder の r が if の i に連結 [ˈwʌndərɪf] ワンダリフ
  • there's の z が a の弱形 /ə/ に連結 [ðɛɹzə] デアーザ
アイ ワンダリフ デアーザ ケイヴ ビロー ディス エリア

⛏I wonder about the behavior of Endermen here.

ここでのエンダーマンの行動について不思議に思う。

/aɪ ˈwʌndərəbaʊt ðə bɪˈheɪvjərəv ˈɛndərmɛn hɪr/
  • wonder の r が about の ə に連結 [ˈwʌndərəbaʊt] ワンダーラバウト
  • behavior の r が of の ə に連結。of は弱形 /əv/ [bɪˈheɪvjərəv] ビヘイヴャーラヴ
アイ ワンダーラバウト ザ ビヘイヴャーラヴ エンダーメン ヒア

⛏A perfect circle structure built entirely by hand is a wonder.

完全に手作りで建造された完璧な円形構造は素晴らしい奇跡だ。

/ə ˈpɜrfɪkt ˈsɜrkəl ˈstrʌkʃər bɪlt ɛnˈtaɪərli baɪ hænd ɪzə ˈwʌndər/
  • is の z が a の弱形 /ə/ に連結 [ɪzə] イザ
ア パーフィクト サークル ストラクチャー ビルト エンタイアリー バイ ハンド イザ ワンダー

🔤 活用形・複数形

is wondering現在進行形（am/is/are + -ing）/ɪz ˈwʌndɚɪŋ/

I'm wondering if we should expand our base to the north.

私たちの基地を北に拡張すべきかどうか気になっている。

/aɪm ˈwʌndɚɪŋ ɪf wi ʃʊd ɪkˈspænd aʊr ˈbeɪs tə ðə ˈnɔrθ/
  • I'm wondering → mが w に連結
  • if we → 語末子音fと次の母音wが連結（f音は保持） [ɪf wi]
  • to the → toは弱形 /tə/ に弱化、theは弱形 /ðə/
アイム ワンダリン イフ ウィー シュド イクスパンド アワー ベイス タ ザ ノース

She is wondering whether this biome has any diamonds.

彼女はこのバイオームにダイヤモンドがあるか気になっている。

/ʃi ɪz ˈwʌndɚɪŋ ˈweðɚ ðɪs ˈbaɪoʊm hæz ˈeni ˈdaɪməndz/
  • She is → 子音終尾 e が i に連結し、isの語末z が w に連結
  • any diamonds → y が d に連結
シー イズ ワンダリン ウェザー ディス バイオーム ハズ エニー ダイアモンズ
was wondering過去進行形（was/were + -ing）/wəz ˈwʌndɚɪŋ/

He was wondering if he had collected enough blocks for the project.

彼はプロジェクト用に十分なブロックを集めたかどうか気になっていた。

/hi wəz ˈwʌndɚɪŋ ɪf hi həd kəˈlɛktɪd ɪˈnʌf blɑks fɔr ðə ˈprɑdʒɛkt/
  • was wondering → wasは弱形 /wəz/、z が w に連結
  • if he → 語末子音fと次の母音が連結（f音は保持） [ɪf hi]
  • for the → r が ə に連結、theは弱形 /ðə/
ヒー ワズ ワンダリン イフ ヒー ハド コレクティド イナフ ブロックス フォー ザ プロジェクト

We were wondering whether the nether portal was close by.

/wi wɚ ˈwʌndɚɪŋ ˈweðɚ ðə ˈneðɚ ˈpɔrtəl wəz ˈkloʊs baɪ/
  • We were → r が w に連結
  • portal was → l が w に連結、wasは弱形 /wəz/

had been wondering過去完了進行形（had been + -ing）/həd bɪn ˈwʌndɚɪŋ/

They had been wondering for hours where the End portal frame was located.

彼らはエンドポータルフレームがどこにあるか何時間も考えていた。

/ðeɪ həd bɪn ˈwʌndɚɪŋ fɔr ˈaʊrz wɛr ðə ˈɛnd ˈpɔrtəl ˈfreɪm wəz ˈloʊkeɪtɪd/

  • been wondering → n が w に連結

By the time we found the village, I had been wondering if it actually existed.

  • if it → 語末子音fと次の母音が連結（f音は保持） [ɪf ɪt̚]
