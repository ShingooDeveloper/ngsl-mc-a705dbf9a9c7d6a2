statistics

名詞/stəˈtɪstɪks/CEFR B2ターゲット1400 #1252ターゲット1900 #573英検準2級 #1333
  1. 【名詞】統計、統計資料（データや情報を数値で表したもの；〈…で〉）
  2. 【名詞】統計学（データを集めて分析する学問分野）（the study of data collection and analysis）
  3. 【名詞】数値成績、スコア（活動やゲームの数値結果）（numerical performance record）

⛏️ マインクラフト例文

⛏Statistics show that diamonds spawn below level 16.

統計によるとダイヤモンドはレベル16以下でスポーンします。

/stəˈtɪstɪks ˈʃoʊ ðæt ˈdaɪmənz ˈspoʊn bɪˈloʊ ˈlɛvəl sɪksˈtin/
  • statistics は末尾子音 /s/ をもち、show の /ʃ/ は別の子音なので直接連結しない。
  • that は /ð/、diamonds は /d/ で始まり子音+子音なのでリンキングなし。
スタティスティクス ショウ ザット ダイモンズ スポーン ビロー レベル シクスティーン

⛏I keep statistics on how many blocks I've destroyed each day.

毎日壊したブロックの数の統計を記録しています。

/aɪ ˈkip stəˈtɪstɪks ˈɑn ˈhaʊ ˈmɛni ˈblɑks aɪv dɪˈstrɔɪd ˈɛtʃ ˈdeɪ/
  • on は前置詞で弱形 /ɑn/ または /ən/。
  • blocks の末尾 /s/、I've の /aɪ/ は子音+母音だが、実際には離れた単語の切れ目。
  • each の末尾 /tʃ/、day の /d/ は子音+子音なのでリンキングなし。
アイ キープ スタティスティクス オン ハウ メニ ブロックス アイヴ ディストロイド エチ デイ

⛏The server statistics reveal that players spend most time building.

サーバーの統計によると、プレイヤーは主に建築に時間を費やしていることがわかります。

/ðə ˈsɝvɚ stəˈtɪstɪks rɪˈvil ðæt ˈpleɪɚz ˈspɛnd ˈmoʊst ˈtaɪm ˈbɪldɪŋ/
  • The は冠詞で弱形 /ðə/。
  • server の末尾 /ɚ/ が statistics の弱母音 /ə/ に連結し、r-linking が生じる [ˈsɝvɚstəˈtɪstɪks]→「サーバー スタティスティクス」。
  • that の末尾 /t/、players の /p/ は子音+子音。
ザ サーバー スタティスティクス リビール ザット プレイヤーズ スペンド モースト タイム ビルディング

⛏According to statistics, players in creative mode build twice as fast.

統計によると、クリエイティブモードのプレイヤーは2倍速く建築できます。

/əˈkɔrdɪŋ tə stəˈtɪstɪks ˈpleɪɚz ɪn kriˈeɪtɪv ˈmoʊd ˈbɪld twaɪs əz ˈfæst/
  • according の末尾 /ŋ/、to の /t/ は子音+子音なのでリンキングなし。
  • to は機能語で弱形 /tə/。
  • statistics の末尾 /s/、players の /p/ は子音+子音。
  • mode の末尾 /d/、build の /b/ は子音+子音。
