forty

数詞・名詞/ˈfɔɹti/CEFR A1ターゲット中学1800 #1237
  1. 【数詞】40を表す基数詞。数量や測定値を示す（We need forty blocks to build this wall.）
  2. 【名詞】数字や数量そのもの。40個の物（Forty is a good width for a base perimeter.）
