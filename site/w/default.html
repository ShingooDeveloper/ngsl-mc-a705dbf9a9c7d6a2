default

名詞・動詞/dɪˈfɔlt/CEFR B1ターゲット1200
  1. 【名詞】システムやゲームで、何も指定されない場合に自動的に使用される設定（preset configuration or default setting）
  2. 【名詞】初期状態；何も変更されていない元々の設定（default state or initial condition）
  3. 【動詞】選択肢がない時に必然的にそれを選ぶ；デフォルトで〜を選ぶ（to choose by default）

⛏️ マインクラフト例文

⛏I need to keep the default game mode.

ゲームモードをデフォルトのままに保つ必要があります。

/aɪ ˈniːd̚ tə kiːp̚ ðə dɪˈfɔlt̚ ɡeɪm moʊd/
  • need の語末 /d/ が弱形 /tə/ に未開放で接続 [ˈniːd̚ tə]→「ニッタ」
  • keep の語末 /p/ が弱形 /ðə/ に未開放で接続 [kiːp̚ ðə]→「キープザ」
  • default の語末 /t/ が子音 /ɡ/ に未開放で接続 [dɪˈfɔlt̚ ɡeɪm]→「ディフォルッ」
