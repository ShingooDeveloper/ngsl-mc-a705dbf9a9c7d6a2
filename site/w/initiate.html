initiate

動詞・名詞/ɪˈnɪʃieɪt/CEFR B2英検準1級 #1366
  1. 【動詞】（プロセス・活動を）開始する、始める（…を開始する）
  2. 【動詞】（人を新しいグループ・スキルに）導入する、入門させる（…に導く）
  3. 【名詞】新しく組織・活動に導入された人、入門者（…をする人）

⛏️ マインクラフト例文

⛏We need to initiate the redstone contraption.

レッドストーン装置を起動する必要があります。

/wiː niːd tə ɪˈnɪʃieɪt̚ ðə ˈrɛdˌstoʊn kənˈtræpʃən/
  • to は機能語で弱形 /tə/ に弱化
  • initiate の語末 /t/ が the の /ð/ の前で未開放 [t̚]
  • the は子音の前なので弱形 /ðə/
ウィー ニード タ イニシエイト ザ レッドストウン コントラプション

⛏She initiated a project to build a village.

彼女は村を建築するプロジェクトを開始しました。

/ʃi ɪˈnɪʃieɪtɪdə ˈprɑdʒɛkt tə ˈbɪldə ˈvɪlɪdʒ/
  • initiated の語末 /d/ が a の /ə/ に連結 [ɪˈnɪʃieɪtɪdə]
  • to は弱形 /tə/
  • build の語末 /d/ が a の /ə/ に連結 [ˈbɪldə]
シー イニシエイティダ プラジェクト タ ビルダ ヴィリッジ

⛏Never initiate combat with a Warden.

Warden との戦闘を開始してはいけません。

/ˈnɛvər ɪˈnɪʃieɪt̚ ˈkɑmbæt̚ wɪðə ˈwɔrdən/
  • never の語末 /ɹ/ が initiate の /ɪ/ に連結 [ˈnɛvərɪˈnɪʃieɪt]
  • initiate の語末 /t/ が combat の /k/ の前で未開放 [t̚]
  • with の語末 /ð/ が a の /ə/ に連結 [wɪðə]→ウィザ
ネヴァー イニシエイト コンバット ウィザ ウォーデン

initiate into〜に入門させる、新しいメンバーとして迎える

⛏They initiated him into the mining guild.

彼らは彼をマイニングギルドに入門させました。

/ðeɪ ɪˈnɪʃieɪtɪd̚ hɪm ˈɪntu ðə ˈmaɪnɪŋ ɡɪld/
  • initiated の語末 /d/ が him の /h/ の前で未開放 [d̚]
  • into: /ɪn/ と /tu/ の間。into は一語で /ɪntu/
  • the は子音前で弱形 /ðə/
