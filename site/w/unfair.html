unfair

形容詞"/ʌnˈfɛr/"CEFR B1英検3級 #950
  1. 【形容詞】不公正な、不公平な
  2. 【形容詞】(条件・状況などが)不利な

⛏️ マインクラフト例文

⛏That rule is unfair to beginners.

その規則は初心者には不公正だ。

/ðæt rul ɪz ʌnˈfɛr tə bɪˈɡɪnərz/
  • rule の語末 /l/ が is の /ɪ/ に連結 [rul ɪz] ルイズ
  • is の語末 /z/ が unfair の /ʌ/ に連結 [ɪz ʌnˈfɛr]
  • to は機能語で弱形 /tə/ に弱化
ザットルイズアンフェアタビギナーズ

⛏He has an unfair advantage in combat.

彼は戦闘で不公正な利点を持っている。

/hi həz ən ʌnˈfɛr ədˈvænɾɪdʒ ɪn ˈkɑmbæt/
  • has の語末 /z/ が an の /ə/ に連結 [həz ən] ハズアン
  • an は弱形 /ən/ に弱化
  • unfair の語末 /r/ が advantage の /ə/ に連結 [ʌnˈfɛr ə]
  • advantage の /t/ は母音に囲まれた弱アクセント音節のフラップT [ɾ]
  • advantage の語末 /dʒ/ が in の /ɪ/ に連結
ヒハズアンアンフェアアドバンリッジインカムバット

⛏The difficulty setting seems unfair.

難度設定が不公正に思える。

/ðə ˌdɪfɪˈkʌɾi ˈsɛɾɪŋ simz ʌnˈfɛr/
  • the は弱形 /ðə/ で発音される
  • difficulty の /t/ はフラップT [ɾ]
  • setting の /t/ は母音に囲まれた弱アクセント音節のフラップT [ɾ]
  • seems の語末 /z/ が unfair の /ʌ/ に連結 [simz ʌnˈfɛr]
