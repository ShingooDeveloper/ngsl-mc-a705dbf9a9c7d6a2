discharge

動詞・名詞/dɪsˈtʃɑːrdʒ/CEFR B1英検準1級 #175
  1. 【動詞】（電気・液体・物質などを）放出する、放電する
  2. 【動詞】（銃・弓から）発射する、射撃する
  3. 【動詞】（職務・責任を）果たす、遂行する
  4. 【名詞】放出、放電；放出物、排液

⛏️ マインクラフト例文

⛏We need to discharge all this redstone power to prevent the machine from overheating.

マシンが過熱するのを防ぐため、このレッドストーン電力をすべて放電する必要があります。

/wi ˈniːd tə dɪsˈtʃɑːrdʒ ɔːl ðɪs ˈrɛdstoʊn ˈpaʊər tə prɪˈvɛnt ðə məˈʃin frəm ˌoʊvərˈhitɪŋ/
  • need to: need の語末 /d/ が to の /tə/ に連結 [niːd‿ə]
  • discharge all: discharge の語末 /dʒ/ が all の /ɔː/ に連結 [dɪsˈtʃɑːrdʒɔːl]
  • from overheating: from の語末 /m/ が overheating の /oʊ/ に連結 [frəmˈoʊvər]
