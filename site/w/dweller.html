dweller

名詞/ˈdwɛlɚ/CEFR B1英検準1級 #2137
  1. 【名詞】住む人、住民。ある場所に住んでいる人（person who lives in a place）
  2. 【名詞】〜に住む生き物。ある環境に生息する動物やモブ（creature that inhabits a place）

⛏️ マインクラフト例文

⛏Cave dwellers often find diamonds deep underground.

洞窟に住む採掘者たちはよく地下深くにダイアモンドを見つける。

/ˈkeɪv ˈdwɛlɚz ˈɔftən ˈfaɪnd ˈdaɪmənz ˈdip ˌʌndɚˈɡraʊnd/
  • dwellers /ˈdwɛlɚz/ の /z/ が often /ˈɔftən/ の /ɔ/ に連結 [ˈdwɛlɚzɔftən]（dwellers often = ドウェラーザ オフテン）
  • find /faɪnd/ の /d/ が diamonds /ˈdaɪmənz/ の /d/ の前で未開放 [faɪn̚ ˈdaɪmənz]（find diamonds = ファイン ダイマンズ）
  • deep /dip/ の /p/ が underground /ˌʌndɚˈɡraʊnd/ の /ʌ/ に連結 [dipʌndɚˈɡraʊnd]（deep underground = ディーパンダーグラウンド）
ケイヴ ドウェラーザ オフテン ファイン ダイマンズ ディーパンダーグラウンド

⛏The Nether dwellers are hostile mobs we must avoid.

ネザーの住民たちは、回避しなければならない敵モブです。

/ðə ˈnɛðɚ ˈdwɛlɚz ɑr ˈhɑstəl mɑbz wi məst əˈvɔɪd/
  • the /ðə/ は弱形で、Nether /ˈnɛðɚ/ に先行（the Nether = ザ ネザー）
  • dwellers /ˈdwɛlɚz/ の /z/ が are /ɑr/ の /ɑ/ に連結 [ˈdwɛlɚzɑr]（dwellers are = ドウェラーザー）
  • must /məst/ の /st/ が avoid /əˈvɔɪd/ の /ə/ の前で未開放 [məs̚ əˈvɔɪd]（must avoid = マス アボイド）
ザ ネザー ドウェラーザー ハースタル モブズ ウィ マス アボイド

⛏Forest dwellers like wolves and deer roam these woods peacefully.

森に住むオオカミやシカなどの生き物たちは、この森の中を平和に歩き回ります。

/ˈfɔrəst ˈdwɛlɚz laɪk wʊlvz ənd ˈdɪr roʊm ðiz wʊdz ˈpisfəli/
  • forest /ˈfɔrəst/ の /t/ が dwellers /ˈdwɛlɚz/ の /d/ の前で未開放 [ˈfɔrəs̚ ˈdwɛlɚz]（forest dwellers = フォレスト ドウェラーズ）
  • and /ənd/ は弱形 [ən] で、deer /ˈdɪr/ の /d/ に先行 [ən ˈdɪr]（and deer = エン ディア）
  • roam /roʊm/ の /m/ が these /ðiz/ に先行するが、/ð/ は子音のため連結なし（roam these = ロウム ディーズ）
フォレスト ドウェラーズ ライク ウルブズ エン ディア ロウム ディーズ ウッズ ピースフリ
