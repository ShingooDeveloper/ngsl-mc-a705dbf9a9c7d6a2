elephant

名詞/ˈɛləfənt/CEFR A1ターゲット中学1800 #806
  1. 【名詞】大きな4足動物で、長い鼻と大きな耳を持つ（a large animal with a long trunk and large ears）
  2. 【名詞】象のように大きく・重いもの
  3. 【名詞】象徴的に忘れない人（an elephant never forgets）

⛏️ マインクラフト例文

⛏I sculpted a stone elephant for our castle entrance.

城の入口用に石象を彫刻しました。

/aɪ ˈskʌlptəd ə ˈstoʊn ˈɛləfənt fɚ aʊɚ ˈkæsəl ˈɛntrəns/
  • a は弱形 /ə/ に弱化
  • stone の /n/ が elephant の /ɛ/ に連結 [ˈstoʊn‿ɛləfənt]
  • for は弱形 /fɚ/、our の /aʊɚ/ と r-linking で連結 [fɚ‿aʊɚ]
アイ スカルプティッド ア ストウン エレファント ファー アワー キャッスル エントレンス

⛏The elephant in the room is that nobody explored the nether yet.

象的な問題は誰もまだネザーを探索していないということです。

/ðə ˈɛləfənt ɪn ðə ˈrum ɪz ðæt ˈnoʊbədi ɪkˈsplɔrd ðə ˈnɛðɚ jɛt/
  • the は子音前で弱形 /ðə/、elephant の /ɛ/ に連結 [ðə‿ɛləfənt]
  • in の /n/ が the の弱形 /ðə/ に連結、the の /ə/ が room の /r/ に連結 [ɪn‿ðə‿rum]
  • nether の /ɚ/ と yet の /j/ は異なる子音なので連結しない

⛏You're like an elephant—you never forget where we hid the treasure!

あなたはまるで象のようです—宝を隠した場所を決して忘れていません！

/jɚ laɪk ən ˈɛləfənt—juː ˈnɛvɚ fərˈɡɛt wɛr wi ˈhɪd ðə ˈtrɛʒɚ/
  • like の /k/ が an の弱形 /ən/ に連結 [laɪk‿ən]
  • where の末尾 /r/ が we の /wi/ に r-linking で連結 [wɛr‿wi]
