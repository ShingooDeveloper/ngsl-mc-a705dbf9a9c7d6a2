whereby

接続詞・副詞/ˌwɛɹˈbaɪ/CEFR B2英検準1級 #2731
  1. 【接続詞】…によって（ある方法や手段により何かが達成されることを示す）
  2. 【副詞】どのような方法で（その手段や過程で・～することで）
  3. 【接続詞】…に従って（ある規則や事実に基づいて・～に応じて）

⛏️ マインクラフト例文

⛏The mob trap whereby we set up fall mechanisms uses gravity to eliminate hostile creatures efficiently.

落下メカニズムを設置する方法のモブトラップは、重力を使って敵性生物を効率的に倒します

[ðə ˈmoʊb ˈtɹæp ˌwɛɹˈbaɪ wi ˈsɛt‿ʌp ˈfɔl ˌmɛkəˈnɪzəmz ˈjuːzɪz‿ə ˈɡrævɪti tu ɪˈlɪmɪneɪt ˈɑstəl ˈkɹitʃɚz ɪˈfɪʃəntli]
  • set /t/ が up の /ʌ/ に連結 [ˈsɛt‿ʌp]→「セタップ」
  • uses /z/ が a の /ə/ に連結 [ˈjuːzɪz‿ə]→「ユーズィズ ア」
  • The /ðə/→ザ - weak form of /ðɪ/
ザ モウブ トラップ ウェアバイ ウィ セタップ フォール メカニズムズ ユーズィズ ア グラビティ トゥ イリミネイト アスタル クリーチャーズ イフィシェントリ

⛏A farming system whereby villagers can breed in confined spaces requires beds, doors, and workstations.

限定されたスペースでヴィレッジャーが繁殖する農業システムは、ベッド、ドア、仕事場が必要です

[ə ˈfɑɹmɪŋ ˈsɪstəm ˌwɛɹˈbaɪ ˈvɪlɪdʒɚz ˈkæn ˈbɹiːd ɪn kənˈfaɪnd ˈspeɪsɪz rɪˈkwaɪɹz ˈbɛdz ˈdɔɹz ənd ˈwɚkˌsteɪʃənz]
  • can /n/ + breed /b/：子音同士なので連結しない [kæn ˈbɹiːd]
  • spaces /z/ + requires /ɹ/：子音同士なので連結しない
  • a /ə/→ア - weak form（冠詞 a の弱形）
ア ファーミング システム ウェアバイ ビリッジャーズ キャン ブリード イン カンファインド スペイセズ リクワイアーズ ベッズ ドーアズ アンド ワークステイションズ

⛏The redstone contraption whereby pistons are activated by lever input uses a simple circuit design.

レバー入力によってピストンが作動する仕掛けは、シンプルな回路設計を使用しています

[ðə ˈɹɛdˌstoʊn kənˈtɹæpʃən ˌwɛɹˈbaɪ ˈpɪstənz ɑɹ ˈæktɪveɪtɪd baɪ ˈlevɚ ˈɪnpʊt ˈjuːzɪz‿ə ˈsɪmpəl ˈsɜɹkət dɪˈzaɪn]
  • uses /z/ が a の /ə/ に連結 [ˈjuːzɪz‿ə]→「ユーズィズ ア」
  • lever /ɹ/ が input の /ɪ/ に R-linking [ˈlevɚ‿ˈɪnpʊt]→「レバー インプット」
  • The /ðə/→ザ - weak form of /ðɪ/
ザ レッストォン コントラプション ウェアバイ ピストンズ アー アクティベイティド バイ レバー インプット ユーズィズ ア シンプル サーキット ディザイン
