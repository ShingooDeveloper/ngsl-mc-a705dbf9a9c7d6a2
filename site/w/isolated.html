isolated

形容詞・動詞/ˈaɪsəleɪtɪd/CEFR B2英検準1級 #642
  1. 【形容詞】孤立した；他から遠く離れた（...far from others）
  2. 【形容詞】孤独な；社会から隔離された
  3. 【動詞】（isolate の過去形・過去分詞）〜を隔離する；孤立させる（...to separate）
  4. 【形容詞】（出来事などが）単独の；個別の

⛏️ マインクラフト例文

⛏This island is completely isolated.

この島は完全に孤立しています。

/ðɪs ˈaɪlənd ɪz kəmˈpliːtli ˈaɪsəleɪtɪd/
  • This island → /s/ が母音 /aɪ/ に連結 [ðɪzˈaɪ] (ディズアイ)
  • is → 弱形 /ɪz/ (イズ)
ディス アイランド イズ カムプリートリー アイソレイティド

⛏I've isolated this area with walls.

このエリアを壁で隔離しました。

/aɪv ˈaɪsəleɪtɪd ðɪs ˈɛriə wɪð wɔlz/
  • I've isolated → /v/ が母音 /aɪ/ に連結 [aɪvˈaɪ] (アイヴアイ)
  • this area → /s/ が母音 /ɛ/ に連結 [ðɪzˈɛ] (ディズエ)
  • with → /ð/ が子音の前で未開放 [wɪðˈwɔ]
