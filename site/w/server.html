server

名詞・動詞/ˈsɜːrvər/CEFR B1頻度#2758
  1. 【名詞】複数のコンピュータやゲーム機がアクセスするコンピュータシステム（connect to a server）
  2. 【名詞】テニスやバレーボールなどでボールを打つ人
  3. 【名詞】飲食店でお客さんに食事や飲み物を提供する従業員
  4. 【動詞】テニスなどでサーブを打つ、または食事や飲み物を配膳する

⛏️ マインクラフト例文

⛏The server is down right now.

今、サーバーがダウンしています。

/ðə ˈsɜːrvər ɪz ˈdaʊn ˈraɪt ˈnaʊ/
  • 「The」は冠詞で弱形 /ðə/ に弱化
  • 「server is」で server の語末の /r/ が is の /ɪ/ に連結
