explorer

名詞/ɪkˈsplɔrər/CEFR B1英検準2級 #1445英検2級 #429
  1. 【名詞】未知の土地を探検する人、探検者。（...explore unknown lands）
  2. 【名詞】秘密の場所や資源を探す者。（...search for hidden locations or resources）
  3. 【名詞】科学的調査や研究を行う人。（...conduct scientific investigations）

⛏️ マインクラフト例文

⛏An explorer found a big cave.

探検家が大きな洞窟を見つけた。

/ən ɪkˈsplɔrər ˈfaʊnd ə ˈbɪɡ ˈkeɪv/
  • 「An explorer」で、An の語末 n が explorer の /ɪ/ に連結 [ən ‿ɪkˈsplɔrər]
  • 「found a」で、found の語末 d が a の /ə/ に連結 [faʊnd ‿ə]
エニクスプローラー ファウンダ ビッグ ケイブ

⛏The explorer is searching for ore.

その探検家は鉱石を探索している。

/ðə ɪkˈsplɔrər ɪz ˈsɝtʃɪŋ fɔr ˈɔr/
  • 「The」が弱形 /ðə/（強形は /ðiː/）
  • 「explorer is」で explorer の語末 r が is の /ɪ/ に連結 [ɪkˈsplɔrɚ ‿ɪz]
  • 「for ore」で for の語末 r が ore の /ɔ/ に連結 [fɔr ‿ɔr]

⛏We met an explorer near an ancient temple.

古い寺の近くで探検家に会った。

/wi ˈmɛt ən ɪkˈsplɔrər ˈnɪr ən ˈeɪnʃənt ˈtɛmpəl/

  • 「an explorer」で an の語末 n が explorer の /ɪ/ に連結 [ən ‿ɪkˈsplɔrər]

  • 「an ancient」で an の語末 n が ancient の /eɪ/ に連結 [ən ‿ˈeɪnʃənt]
