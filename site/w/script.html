script

名詞・動詞/ˈskrɪpt/CEFR B2ターゲット1900 #1244
  1. 【名詞】映画や演劇などの台本、脚本（written text for a play or film）
  2. 【名詞】コンピュータプログラムの命令セット、スクリプト（set of programmed commands or code）
  3. 【名詞】手書き文字、筆記体（handwriting or cursive writing style）
  4. 【動詞】台本を書く、命令セットを作成する（write a script or create a set of instructions）
