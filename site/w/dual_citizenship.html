dual_citizenship

名詞/ˈduːəl sɪˈtɪzənʃɪp/CEFR B2英検準1級 #1451
  1. 【名詞】2つ以上の国の市民権をもつ法的身分。
  2. 【名詞】複数のコミュニティやサーバーへのアクセス権をもつプレイヤーの地位（the status of having membership or rights in multiple server communities）。
  3. 【名詞】二重国籍。二重身分（the condition of holding two nationalities or statuses）。

⛏️ マインクラフト例文

⛏Players achieving dual citizenship gain access to both faction territories.

二重市民権を得たプレイヤーは両方のファクション領土にアクセスできます。

/ˈpleɪɚz əˈtʃiːvɪŋ ˈduːəl sɪˈtɪzənʃɪp ɡeɪn ˈæksɛs tə boʊθ ˈfækʃən ˈtɛrətɔːriz/
  • achieving dual → /ŋ/→/d/ 隣接（ng + d で連結なし）
  • citizenship gain → /p/→/ɡ/ 隣接（語末 /p/ が語頭 /ɡ/ に接するが連結なし）
  • access to → to の弱形 /tə/（/s/ と /t/ 隣接）
  • both faction → /θ/→/f/ 隣接（th + f で連結なし）
プレイヤーズ アチーヴィング デュアル シティズンシップ ゲイン アクセス タ ボース ファクション テリトリーズ

⛏Dual citizenship allows you to claim land on both server worlds.

二重市民権があれば、両方のサーバー世界に土地請求ができます。

/ˈduːəl sɪˈtɪzənʃɪp əˈlaʊzjuː tə klɛɪm ˈlændɑn boʊθ ˈsɚvɚ wɚldz/
  • allows you → /z/→/j/ に連結（allows の語末 /z/ が you の半母音 /j/ に連結）[əˈlaʊzjuː] → アラウズユー
  • land on → /d/→/ɑ/ に連結（land の語末 /d/ が on の /ɑ/ に連結）[ˈlændɑn] → ランドオン
  • to claim → to は機能語で弱形 /tə/（機能語の弱化）[tə klɛɪm] → タ クレイム
  • both server → /θ/→/s/ 隣接（th + s で連結なし。server は /ˈsɚvɚ/）
デュアル シティズンシップ アラウズユー タ クレイム ランドオン ボース サーヴァー ワールズ

⛏The server requires dual citizenship to build on protected land.

サーバーは保護地に建築するために二重市民権を必要とします。

/ðə ˈsɚvɚ rɪˈkwaɪɚz ˈduːəl sɪˈtɪzənʃɪp tə bɪld ɑn prəˈtɛktɪd lænd/
  • The server → the は機能語で弱形 /ðə/（定冠詞の弱化）[ðə ˈsɚvɚ] → ザ サーヴァー
  • citizenship to → to の弱形 /tə/（/p/ と /t/ 隣接）
  • build on → /d/→/ɑ/ に連結（build の語末 /d/ が on の /ɑ/ に連結）[bɪld ɑn] → ビルドオン
  • protected land → /d/→/l/ 隣接（protected の語末 /d/ が land の /l/ に接するが連結なし）
