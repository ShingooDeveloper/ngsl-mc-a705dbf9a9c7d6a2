right_off

副詞/ˈraɪt ɔːf/CEFR B1英検準1級 #633
  1. 【副詞】すぐに、ただちに、すぐさま（直後に行動を起こす、躊躇しない）
  2. 【副詞】率直に、ぶっきらぼうに（言葉に対して）
  3. 【副詞】最初から、最初の瞬間に（right from the start のニュアンス）

⛏️ マインクラフト例文

⛏I noticed the spider right off and started running toward the base.

クモをすぐに気づいて、拠点に向かって走り始めた。

/aɪ ˈnoʊɾɪst ðə ˈspaɪdɚ ˈraɪɾ‿ˈɔf ənd ˈstɑːɾəd ˈrʌnɪŋ təˈwɔrd ðə ˈbeɪs/
  • noticed the → noticed の語末 /d/ が the の /ð/ に連結
  • right off → right の語末 /t/ が off の /ɔ/ に連結してフラップT化 [ˈraɪɾɔf]
  • and started → and は弱形 /ənd/。started の /t/ は母音に挟まれてフラップ化 [əndˈstɑːɾəd]
アイ ノウティス ダ スパイダー ライラフ エン スターラッド ラニング トゥワード ダ ベイス

⛏Right off, I can tell this ore is different from what I've mined before.

最初から分かるんだけど、この鉱石は今まで掘ったものとは違う。

/ˈraɪɾ‿ˈɔf | aɪ kən ˈtɛl ðɪs ˈɔr ɪz ˈdɪfɚənt frəm ˈwʌt̚ aɪv ˈmaɪnd bɪˈfɔːr/
  • right off → right の語末 /t/ が off の /ɔ/ に連結してフラップT化 [ˈraɪɾɔf]
  • I can → can は文中なので弱形 /kən/
  • this ore → this の語末 /s/ が ore の /ɔ/ に連結
  • from → 弱形 /frəm/
  • I've → have は 've に短縮
ライラフ、アイ カン テル ディス オア イズ ディファレント フラム ワット アイヴ マインド ビフォー

⛏You have to grab the supplies right off when the chest opens, or the other player will take them.

チェストが開いたらすぐに物資をつかまないと、他のプレイヤーに取られてしまう。

/ju ˈhæv tə ˈɡræb ðə səˈplaɪz ˈraɪɾ‿ˈɔf wɛn ðə ˈtʃest ˈoʊpənz | ɔr ðə ˈʌðɚ ˈpleɪɚ wɪl ˈteɪk ðəm/
  • have to → have は弱形、to も弱形 /tə/
  • right off → right の語末 /t/ が off の /ɔ/ に連結してフラップT化 [ˈraɪɾɔf]
  • opens or → opens の /z/ が or の /ɔ/ に連結
