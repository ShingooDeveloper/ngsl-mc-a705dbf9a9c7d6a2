easygoing

形容詞/ˌiːziˈɡoʊɪŋ/CEFR B1英検準1級 #1641
  1. 【形容詞】のんびりした、気さくな、さっぱりした（...easygoing personality...）
  2. 【形容詞】気を許した、おおらかな、人付き合いが良い（...easygoing attitude...）
  3. 【形容詞】厳密でない、ゆるい規則（...easygoing rules...）

⛏️ マインクラフト例文

⛏Our server admin is pretty easygoing about the build rules.

私たちのサーバー管理者は建築ルールについてかなり気さくだ。

/ˈaʊr ˈsɝvər ˈædmɪn ɪz ˈprɪɾi ˌiːziˈɡoʊɪŋ əˈbaʊt ðə ˈbɪld ˈrulz/
  • admin is → 語末子音 /n/ が母音 /ɪ/ に連結。[ˈædmɪn‿ɪz] アドミン・イズ
  • pretty easygoing → pretty の語末 /t/ がフラップ化。[ˈprɪɾi]。easygoing 頭 /i/ に連結
  • about the → about の語末 /t/ が the の弱形 /ðə/ に連結してフラップ化。[əˈbaʊɾə]
アワー サーヴァー アドミン イズ プリリ イージーゴーイング アバウラ ザ ビルド ルーズ

⛏That easygoing player never complains when losing items in the lava.

あのんびりした選手は溶岩でアイテムを失うときに決して文句を言わない。

/ðæt ˌiːziˈɡoʊɪŋ ˈpleɪər ˈnɛvər kəmˈpleɪnz wɛn ˈluzɪŋ ˈaɪtəmz ɪn ðə ˈlɑːvə/
  • easygoing player → 語末子音 /ŋ/ が母音 /p/ に連結。[ˈɡoʊɪŋ‿ˈpleɪər] ゴーイング・プレイヤー
  • losing items → 語末子音 /ŋ/ が母音 /aɪ/ に連結。[ˈluzɪŋ‿ˈaɪtəmz] ルージング・アイテムズ
  • in the → the は弱形 /ðə/。[ɪn‿ðə] イン・ザ
ザット イージーゴーイング プレイヤー ネヴァー カムプレインズ ウェン ルージング アイテムズ イン ザ ラーヴァ

⛏I prefer an easygoing team over strict players.

私は厳格なプレイヤーより気さくなチームの方が好きです。

/aɪ prɪˈfɝ ən ˌiːziˈɡoʊɪŋ tim ˈoʊvɚ strɪkt ˈpleɪərz/
  • prefer an → prefer の語末子音 /r/ が母音 /ə/ に連結。[prɪˈfɝ‿ən] プリファー・アン
  • easygoing team → 語末子音 /ŋ/ が team に連結。[ˈɡoʊɪŋ‿tim] ゴーイング・ティーム
  • strict players → strict の語末 /t/ が players に連結するため未開放。[strɪk‿ˈpleɪərz]
アイ プリファー アン イージーゴーイング ティーム オーヴァー ストリク プレイヤーズ
