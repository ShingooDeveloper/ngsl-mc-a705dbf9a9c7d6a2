worse

形容詞・副詞/wɝz/CEFR A2ターゲット1000 #647
  1. 【形容詞】（bad の比較級）より悪い、より劣った。品質や状態が低下している（This tool is worse than that one）。
  2. 【形容詞】より健康でない、より悪化した。体調や状態が悪くなる（Your condition is getting worse）。
  3. 【副詞】より悪く、一層悪く。より不利な、より負の状況で（perform worse）。
  4. 【副詞】（worse yet / to make matters worse）さらに悪いことに、事態を一層複雑にする。

⛏️ マインクラフト例文

⛏This wooden pickaxe is worse than that iron pickaxe, so I need to find better tools.

この木のツルハシはあの鉄のツルハシより悪いので、もっといい道具を見つける必要があります。

/ðɪs ˈwʊdən ˈpɪkˌæks ɪz wɝz ðæn ðæt ˈaɪrən ˈpɪkˌæks soʊ aɪ ˈniːd tu faɪnd ˈbɛtər ˈtulz/
  • This → /ðɪs/ ディス
  • pickaxe is → 語末の /s/ が /ɪ/ に連結。is は弱形 /ɪz/ [ˈpɪkˌæks ɪz] ピックアクシズ
  • is worse → /z/ が /w/ に連結 [ɪz wɝz] イズワース
