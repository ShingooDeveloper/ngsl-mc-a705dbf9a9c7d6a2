skim

動詞・名詞/skɪm/CEFR B1英検準1級 #1575
  1. 【動詞】素早く読む、ざっと目を通す（skim a text）
  2. 【動詞】液体の表面から〜を取り除く（skim cream from milk）
  3. 【動詞】表面すれすれに動く、かすめて通る（the stone skimmed across the water）
  4. 【名詞】液体の表面から取り除いたもの（泡、クリームなど）

⛏️ マインクラフト例文

⛏I skimmed the guide to build an enchanting table.

エンチャンティングテーブルを作るためにガイドをざっと読んだ。

/aɪ ˈskɪmd ðə ɡaɪd tə ˈbɪld ən ɛnˈtʃæntɪŋ ˈteɪbəl/
  • skimmed the → the は弱形 /ðə/
  • guide to → to の弱形 /tə/
  • build an → build の /d/ が an に連結
アイ スキムド ザ ガイド タ ビルダン エンチャンティング テイブル

⛏The arrow skimmed across the lava lake.

矢が溶岩湖を掠めて飛んだ。

/ðə ˈæɹoʊ ˈskɪmd əˈkrɔs ðə ˈlɑvə ˈleɪk/
  • the arrow → the は弱形 /ðə/
  • skimmed across → across の弱形 /əkrɔs/
  • the lava → the は弱形 /ðə/ で /l/ に続く
ザ アロー スキムド アクロス ザ ラーヴァ レイク

⛏I need to skim some strategies before exploring the Nether.

ネザーを探索する前に、いくつかの戦略をざっと読む必要がある。

/aɪ ˈniːd tə ˈskɪm səm ˈstɹætədʒiz bɪˈfɔɹ ɪkˈsplɔɹɪŋ ðə ˈneðɚ/
  • need to → to の弱形 /tə/
  • the Nether → the は弱形 /ðə/ で /n/ に続く
  • before exploring → before の /ɚ/ が exploring の /ɪ/ に連結
アイ ニーダ スキム サム ストラテジーズ ビフォー イクスプローリング ザ ネザー
