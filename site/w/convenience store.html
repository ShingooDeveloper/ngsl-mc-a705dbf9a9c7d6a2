convenience store

名詞/kənˈvɪniəns stɔr/CEFR B1ターゲット中学1800 #1471
  1. 【名詞】日用品・スナック・飲み物などを扱う小売店。長時間営業（often 24/7）（a store that is open late or all night and sells snacks, drinks, and everyday items）
  2. 【名詞】利便性を重視した小規模な商店

⛏️ マインクラフト例文

⛏I need to go to the convenience store and buy supplies for our mining trip.

鉱山採掘用の補給品を買いに便利店に行く必要があります。

🔤 活用形・複数形

convenience stores複数形/kənˈveniəns stɔrz/

We've set up convenience stores in several villages to trade emeralds for essential items.

複数の村にコンビニエンスストアを設置して、エメラルドで必需品と交換できるようにしました。

/wiv ˈsɛt ˈʌp kənˈveniəns ˈstɔrz ɪn ˈsɛvərəl ˈvɪlɪdʒɪz tə ˈtreɪd ˈɛmərəldz fər ɪˈsɛnʃəl ˈaɪɾəmz/
  • set up → 語末子音 /t/ が up の初頭 /ʌ/ に連結 [ˈsɛt ʌp] セット アップ
  • convenience stores → /s/ + /s/ が続く（子音+子音、連結なし）
  • in several → /n/ + /s/ が続く（子音+子音、連結なし）
  • for essential → for は前置詞で弱形 /fər/ で、essential の初頭 /ɪ/ に連結 [ˈfɚ ɪˈsɛnʃəl] ファー イセンシャル
