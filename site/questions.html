疑問文の型 時制 × 5W3H × 人称

疑問詞: What（何を） / Who（誰が） / When（いつ） / Where（どこで） / Why（なぜ） / How（どのように） / How many（いくつ（数）） / How much（どれくらい（量））

疑問詞で始めて、時制ごとに次の語順を作ります。

現在形疑問詞 + do/does + 主語 + 動詞原形?
過去形疑問詞 + did + 主語 + 動詞原形?
未来形（will）疑問詞 + will + 主語 + 動詞原形?
現在進行形疑問詞 + am/is/are + 主語 + 動詞ing?
過去進行形疑問詞 + was/were + 主語 + 動詞ing?
未来進行形疑問詞 + will + 主語 + be + 動詞ing?
現在完了形疑問詞 + have/has + 主語 + 過去分詞?
過去完了形疑問詞 + had + 主語 + 過去分詞?
未来完了形疑問詞 + will + 主語 + have + 過去分詞?

各例文の人称バッジは主語です。Who は「誰が」を尋ねる主語疑問なので、Who + 動詞?（助動詞が前に出ない）の語順になります（例: Who mined this cave?）。
