administrator account

熟語
  1. 管理者アカウント。完全な管理権限を持つコンピューターアカウント。サーバーやPCの全機能にアクセス可能（...only an administrator account can install mods...）。

⛏️ マインクラフト例文

⛏You need an administrator account to change the server settings.

サーバー設定を変更するには管理者アカウントが必要です。
