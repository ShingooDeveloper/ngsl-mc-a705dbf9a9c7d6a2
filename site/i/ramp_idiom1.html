ramp up

熟語
  1. 〜を大幅に増やす、急速に増加させる

⛏️ マインクラフト例文

⛏We need to ramp up ore production to build the new base.

新しい拠点を建設するための鉱石生産を増やす必要があります。

[wiː ˈniːd tə ræmp ʌp ˈɔr prəˈdʌkʃən tə ˈbɪld ðə ˈnjuː ˈbeɪs]
  • need to: need の語末 /d̚/（未開放）が to の /t/ に続く [ˈniːd̚ tə] ニード タ

  • up ore: up の /p/ が ore の /ɔ/ に続く。子音+母音のため連結は起こらない [ʌp ˈɔr] アップ オア
  • production to: production の語末 /n̚/（未開放）が to の /t/ に続く [ʃən tə] シェン タ
