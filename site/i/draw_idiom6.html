draw out

熟語英検準1級 #637
  1. 延長する、長くする、引き伸ばす

⛏️ マインクラフト例文

⛏The better way to set up the redstone gate is to draw out the signal and let it pass through correctly.

赤石ゲートを正しく設置するには、信号経路を延長して正しく通すことが重要な方法です。

[ðə ˈbɛɾɚ ˈweɪ tə ˌsɛt‿ʌp ðə ˈrɛdˌstoun ˈɡeɪt ɪz tə ˈdrɔ aʊt ðə ˈsɪɡnəl‿ænd ləd‿ɪt ˈpæs θru kəˈrɛktli]
  • better → t が母音に挟まれてフラップ化 [ˈbɛɾɚ]→「ベラー」
  • set up → 語末子音 /t/ が母音 /ʌ/ に連結 [sɛt‿ʌp]→「セットアップ」
  • signal and → 語末子音 /l/ が母音 /æ/ に連結 [ˈsɪɡnəl‿ænd]→「シグナルアンド」
  • let it → 弱形 [ləd] が母音 /ɪ/ に連結 [ləd‿ɪt]→「レディット」
